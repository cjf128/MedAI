# MedAI 日报 · MedAI Evidence Brief

医学人工智能证据与行业简报，聚焦"AI + 医疗健康"交叉领域。

## 概览

| 项目 | 说明 |
|------|------|
| **定位** | 医学 AI 每日信息汇点，覆盖医学影像、临床决策、医疗大模型、医疗Agent 等方向 |
| **产出** | 纯静态单文件 HTML（零依赖），学术暗绿色调 |
| **入口** | `index.html` — 固定为最新一期 |
| **收录边界** | 必须同时具备"医学/临床"与"AI/计算"双重属性；纯医学或纯 AI 不收录 |

## 日报结构（两版块固定顺序）

| 版块 | 配色 | 内容 |
|------|------|------|
| 论文研究 📄 | 薄荷绿 `#78e6bd` | 期刊论文与 ArXiv 预印本，按研究点分段 |
| 行业动态 📊 | 蓝 `#70b9ff` | 医疗 AI 政策/合作/融资/安全事件/产品发布 |

### 论文研究二级分段

**固定研究点**（6 个）：
- 医学图像分割
- 疾病诊断
- 医学基础模型
- 医疗Agent与临床智能体
- 世界模型
- PET/CT

## 数据源

- **行业动态**：AI HOT + 关键词筛选（`medical` / `health`）
- **论文研究**：6 本重点期刊必查 + ArXiv 补充
  - IEEE TMI、MIA、JBHI
  - Nature Communications、npj Digital Medicine、Nature Biomedical Engineering
- **检索窗口**：执行日前 90 天内
- **核验要求**：每篇论文至少核验一个大学/研究机构

## 目录结构

```
MedAI/
├── README.md             # 本文件
├── AGENTS.md             # 项目规则与工作流定义
├── template.html         # 设计模板（只读，不含真实数据）
├── index.html            # 最新一期公开首页
└── daily/                # 历史日报归档
    └── YYYY-MM-DD.html
```

## 使用方式

1. 由外部调度器按 `AGENTS.md` 规则每日执行
2. 生成前先将当前 `index.html` 归档至 `daily/YYYY-MM-DD.html`
3. 新内容写入 `index.html`，替换为最新一期
4. 同日重复生成为修订模式，直接覆盖当前 `index.html`

## 设计规范

- 暗绿色调：背景 `#07100e`，强调色 `#78e6bd`（薄荷绿）
- 模板标识：`data-template="clinical-dossier-v1"`
- 宋体/中宋标题，学术感排版
- 证据标签：预印本 / 会议论文 / 综述 / 官方公告 / 媒体报道
- 底部强制医学免责声明（珊瑚色边框）
- 编码：UTF-8，行尾：LF，样式脚本全部内联

## 重要声明

> 本简报仅供学术参考，不构成医疗建议。所有论文解读均标注证据等级，不解读疗效，不替代专业诊断。
