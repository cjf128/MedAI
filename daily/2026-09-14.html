少标注下 PET/CT 融合引导肺穿刺：分割并给出进针路径

术前 PET/CT 能定位代谢活跃病灶，但穿刺时患者体位与呼吸状态改变，术前 PET/CT 与操作 CT 之间存在形变；同时 PET/CT 的像素级标注稀缺，逐例勾画成本极高。安徽省铜陵市人民医院核医学科联合该院心胸外科与铜陵医学科学院，提出面向 CT 引导经皮肺病灶穿刺的迁移学习多模态融合模型：用切片级二维 nnU-Net 做病灶分割，以双流结构分别提取 PET 与 CT 特征并经多尺度交叉注意力融合，在源域预训练后通过半监督域适应迁移到本院数据，最后在分割结果上自动生成进针路径建议。

  • 研究痛点PET/CT 像素级标注稀缺；术前 PET/CT 与操作 CT 存在形变与配准误差；人工规划穿刺路径依赖经验、耗时长且并发症风险与操作者相关。
  • 方法与数据单中心回顾性 140 例；切片级 2D nnU-Net 分割 + 双流 PET/CT 特征提取 + 多尺度交叉注意力融合；源域预训练与半监督域适应（SSDA）；分割指标为 DSC、95% Hausdorff 距离、平均表面距离、真阳性率与阳性预测值；消融考察预训练、SSDA、多模态融合与 10%/30%/50% 标注比例。
  • 局限与迁移单中心 140 例，未做外部验证；摘要未给出训练/测试划分比例、对照组具体数值与置信区间；自动进针“成功率”的判定标准未披露；路径安全性评价仍是模拟层面的潜在并发症计数，不是患者结局。对本项目的迁移价值是“少标注 + 预训练迁移 + 半监督域适应”这一训练配方，以及“分割结果直接驱动下游临床动作并单独评估”的思路；鼻咽癌颈部小淋巴结体积更小、解剖约束更复杂，迁移属研究假设。

CNN 从 FDG PET/CT 鉴别卵巢肿瘤良恶性

盆腔肿块的良恶性判断直接决定手术范围与术前沟通，但影像表现重叠时最终往往要等术后病理。韩国仁济大学医学院釜山白医院核医学科纳入 101 例术前接受 18F-FDG PET/CT、术后有明确病理结果的盆腔肿块患者，比较 ResNet-18 与一个结构更简单的 CNN 在 PET/CT 上区分良恶性的能力，并用 Grad-CAM 生成热力图检查模型关注区域是否落在病灶上。

  • 研究痛点良恶性盆腔肿块的影像表现重叠，单纯目测判读不稳定；缺少可在术前提供客观概率、并可解释关注区域的轻量工具。
  • 方法与数据2020 年 1 月至 2023 年 12 月单中心 101 例，按组织病理分为良性与恶性两组；两种 CNN（ResNet-18 与简单 CNN）在 FDG PET/CT 上训练与评估；报告准确率、AUC、敏感度与特异度，并以 Grad-CAM 可视化判别依据。
  • 局限与迁移单中心 101 例，样本量小；摘要未说明是独立测试集还是交叉验证，也未给出置信区间与类别分布；未披露输入是二维切片还是三维块、SUV 归一化与切片选取方式；无外部验证，无公开代码。对本项目的价值有限，主要作为“核医学影像 + 轻量 CNN + Grad-CAM 可解释性”的入门级可复现基线参照；迁移到 PET/CT 肿瘤分割需另配像素级标注与体积级评估，属研究假设。

PET/CT 双任务学习同步预测肺癌病理亚型与 EGFR

病理亚型与 EGFR 突变状态决定非小细胞肺癌的个体化治疗，但活检有创、难以动态监测，也难反映肿瘤整体异质性。深圳大学医学部生物医学工程学院联合广东省人民医院（广东省医学科学院）核医学科 PET 中心，提出双模态双任务预测模型 DMDP：从 CT 提取亚区域放射组学特征，从 PET 提取空间代谢异质性描述子，用多尺度交叉注意力融合两种模态，并通过双任务学习同时预测 EGFR 突变与病理亚型。

  • 研究痛点传统活检有创且难以重复；同时预测两个临床终点的可解释深度学习模型稀缺；PET 与 CT 的互补信息缺少统一融合框架。
  • 方法与数据回顾性纳入 384 例非小细胞肺癌 PET/CT，来自三个独立队列；CT 侧亚区域放射组学特征 + PET 侧空间代谢异质性特征；多尺度交叉注意力融合 + 双任务学习；消融实验验证各组件贡献，Grad-CAM 评估决策可解释性。
  • 局限与迁移回顾性设计；EGFR 预测 AUC 的 95% 置信区间上限为 1.00（0.81–1.00），提示测试集规模有限；摘要未给出各队列样本量、划分方式与统计检验细节；模型依赖肿瘤区域先验（需分割或勾画），与“免勾画”路线相比落地成本更高。迁移价值：“CT 结构 + PET 代谢双流 + 多任务监督”是可直接借鉴的多模态建模结构，用于鼻咽癌时需重新定义临床终点（如分期、复发或治疗反应）并在本院数据上验证，属研究假设。

PET/CT 放射组学加 2.5D 深度特征预测胰腺癌淋巴结转移

胰腺导管腺癌术前判断淋巴结转移直接影响手术范围与预后分层，但影像上难以可靠识别微小转移结。哈尔滨医科大学附属第二医院核医学科/PET 中心联合滨州医学院附属医院放射科，构建了一个可解释的 PET/CT 人工智能模型：把临床指标、PET/CT 放射组学特征与基于 ResNet50 的 2.5D 深度学习特征合并建模，并用 SHAP 解释各特征的贡献。

  • 研究痛点术前无创判断淋巴结转移困难；单一模态或单一特征族的判别力有限；模型若不可解释，临床难以采信。
  • 方法与数据173 例经病理证实的胰腺导管腺癌，术前 18F-FDG PET/CT，按 7:3 随机划分为训练集与测试集（105 例淋巴结转移阳性、68 例阴性）；特征经 Spearman 相关与逻辑回归筛选；比较支持向量机、逻辑回归、随机森林、极端随机树、梯度提升机、K 近邻与线性判别分析七种算法；以 ROC、DeLong 检验、校准曲线、Hosmer-Lemeshow 检验与决策曲线分析评估，并用 SHAP 做可解释性分析。
  • 局限与迁移单中心 173 例；训练集 AUC 0.970 而测试集最优为 0.871，作者明确指出训练集存在疑似过拟合；最终最优模型是线性判别分析等浅层分类器，而非端到端深度模型；随机 7:3 划分而非外部验证；2.5D 表示的切面选取规则未披露；无公开代码。对本项目的价值是“深度特征 + 放射组学 + 临床变量的可解释融合”这一评估与解释范式；迁移到 PET/CT 鼻咽癌需重新选择终点并做外部验证，属研究假设。

MedCure：用四分之一数据逼近全量视觉语言预训练

医学视觉语言预训练通常依赖百万级图文对与大量算力，而公开医学数据质量参差，简单堆量的边际收益下降很快。阿德莱德大学与澳大利亚机器学习研究所（AIML）提出主动式医学数据筛选框架 MedCure：在预训练过程中建立无向数据图刻画样本重要性，通过邻域信息传播动态更新每个样本的难度分数，再用反向难度传递机制自适应地挑选同时覆盖“难例”与数据空间异质区域的子集，并同时兼顾难度与多样性两个维度。

  • 研究痛点大规模预训练算力成本高；公开图文对质量不均；“数据质量比数量更重要”缺少可操作的子集挑选方法。
  • 方法与数据在超过 120 万胸片图文对上评估；仅使用 25% 的预训练数据、约 32.7% 的训练成本，即达到与全量训练可比的结果；下游评估覆盖疾病分类、跨模态检索、病灶与解剖分割、放射报告生成等零样本泛化与适配任务。
  • 局限与迁移IEEE TIP 在线优先发表，尚未进入正式卷期；摘要未给出逐任务数值与统计检验；核心实验模态为二维胸片，未覆盖三维 PET/CT；数据筛选本身需要额外的图构建与前向计算开销。迁移价值：为“算力受限时如何挑选 PET/CT 预训练子集”提供了可复现的筛选框架；PET/CT 三维体数据与 SUV 定量语义需重新定义样本难度度量，属研究假设。

FedSAM-3D：不共享数据也能多中心迁移三维分割基础模型

三维医学分割基础模型（如 SAM-Med3D）具备很强的零样本能力，但直接全量微调会破坏预训练表征，而多中心数据因隐私与合规无法集中。复旦大学类脑智能科学与技术研究院团队提出 FedSAM-3D：以 SAM-Med3D 为骨干，把协作优化空间严格限制在 adapter 参数内、冻结预训练骨干，通过联邦优化在各中心之间聚合知识，同时允许每个客户端把基础模型适配到本土数据分布。

  • 研究痛点多中心数据分布异构且不能出域；现有适配策略难以在保护隐私的前提下协同迁移基础模型并保持其可迁移表征。
  • 方法与数据在多中心腹部器官分割与脑肿瘤分割数据集上做联邦适配与零样本评估；对照消融变体与现有分割方法；在未见过的外部数据集上检验泛化，并包含跨模态评估；作者报告在两项任务与多个临床数据集上总体优于对照方法。
  • 局限与迁移IEEE TBME 在线优先发表，尚未进入正式卷期；摘要未给出数据集名称、Dice 数值、参与中心数量与统计检验；摘要未量化通信与训练开销；本文机构信息未在 PubMed 摘要中直接给出，本次依据 AMiner 收录条目核验为复旦大学类脑智能科学与技术研究院。迁移价值：对本项目“多中心 PET/CT 不能出院、又要共享模型能力”的现实约束，“冻结骨干 + adapter 联邦”是可直接借鉴的范式；PET/CT 双通道输入与 SUV 强度分布差异需重新设计 adapter 与归一化策略，属研究假设。

TEAMS：文本提示驱动的时空双头 Mamba Snake 轮廓分割

语义分割容易产生掩膜空洞与锯齿边缘，deep snake 一族方法通过预测目标级轮廓规避这一问题，但在形态变化剧烈、细节结构精细以及基础检测出错时仍不稳定。中山大学智能工程学院联合浙江大学医学院附属杭州市第一人民医院与美国凯斯西储大学提出 TEAMS：用时空蛇形演化策略在状态空间模型中同时捕获轮廓上的双向空间依赖与跨演化步的时间动态；用轮廓形态感知 Mamba 量化局部轮廓形态，并据此调制 Mamba2 SSD 对偶形式的结构化注意力掩码；再用文本提示协作双头把文本线索引入轮廓演化，并把演化后的轮廓信息回传给检测头以修正误检。

  • 研究痛点复杂形态变化下轮廓演化不稳；精细器官细节刻画不足；基础检测器误检会直接传导为错误实例。
  • 方法与数据在覆盖不同器官与成像模态的 5 个数据集上评估；相较现有语义分割与 deep snake 方法，在脊柱数据集上取得 mDice/mBF 相对提升 6.9%/9.1%；作者报告在多个场景下优于对照方法。
  • 局限与迁移摘要未列出具体数据集名称、绝对指标与统计检验；主要面向二维实例级轮廓，三维 PET/CT 的代谢边界模糊、部分体积效应显著，轮廓先验未必成立；文本提示的语义空间需要针对 PET/CT 报告重新训练与对齐。迁移价值：对本项目“鼻咽癌原发灶与颈部淋巴结的不规则边界”这一痛点，“轮廓演化 + 文本提示 + 检测头回传”是一条可检验的替代路线；需在 PET/CT 三维数据上重新验证，属研究假设。

基础模型嵌入能否替代放射组学：头颈癌远处转移对照

用影像预测头颈癌远处转移风险的现有方法大多要求先给出肿瘤分割，而分割依赖专家勾画、耗时且引入操作者间差异。美国德克萨斯大学西南医学中心放射肿瘤科 AIRT 与 MAIA 实验室把问题重设为更省人工的形式：直接把最少预处理后的 CT 体数据交给影像基础模型取特征，与传统依赖 ROI 先验的路线做同条件对照。

  • 研究痛点现有影像预测流程依赖专家勾画 ROI，标注成本高、可复现性差；基础模型能否在“免勾画”条件下提供可比特征缺少量化对照。
  • 方法与数据使用公开 RADCURE 数据集 2327 例术前 CT；构造三套特征——放射组学特征、深度学习特征、CT 基础模型嵌入；三套特征各自送入多层感知机预测远处转移风险；以 5 折交叉验证选模，在留出测试集上评估。
  • 局限与迁移预印本未经同行评审；模态仅为 CT，不含 PET 代谢信息；绝对 AUC 约 0.79，距临床可用仍有距离；摘要未报告置信区间、事件数与分层结果；所用 CT 基础模型为第三方模型，其训练数据与目标人群未披露。迁移价值：为本项目提供一条可检验假设——在 PET/CT 上，少预处理的基础模型嵌入能否接近“先勾画 GTV 再提取特征”的路线，从而显著降低标注成本；需在本院 PET/CT 数据上重新验证，属研究假设。

  • 研究痛点网页对话环境与本地编码环境之间上下文不互通；会话不跨轮次保留状态；项目背景重建耗时且易遗漏决策。
  • 方法与数据端到端流水线集成自建网页应用、自托管 n8n 自动化服务、Claude API（Anthropic）、GitHub 版本控制与 Obsidian 知识库；研究设计为单人、单操作者、跨三个并行开发项目的概念验证功能验证，明确声明不做疗效、可用性或临床结局主张，且不处理患者数据。功能测试中，一个 558 token 的会话被完整抽取为六字段；针对 GitHub Contents API 的创建与编辑在连续五次运行中无覆盖错误；本地编码智能体冷启动后可自主复述项目身份、历史技术决策与待办。

把体数据“读对”：方向、间距与重采样插值

一个三维医学影像体不只是像素立方体，它由像素数组加一组几何元数据共同定义：origin（原点）、spacing（体素间距）与 direction（方向余弦矩阵）。PET/CT 尤其容易出问题——同一检查里 PET 与 CT 的矩阵大小、层厚与重建视野都不同，而不同厂商导出到 NIfTI 时对 LPS 与 RAS 坐标系的约定也可能不同。SimpleITK 官方文档把图像定义为“空间中的物理对象”，所有重采样、配准与裁剪都在物理空间而非索引空间中进行。这件事之所以关键，是因为几何元数据一旦处理错，模型学到的可能是设备与协议的差异：层厚 3.75 mm 的 PET 与 1 mm 的 CT 融合时，重采样间距与插值方式直接决定小病灶的峰值是否被抹平，也决定 PET 与 CT 是否真的对齐。

  • 操作要点① 读入后先打印并存档 origin、spacing、direction 与 size，把它们写进实验记录；② 图像重采样用线性或 B 样条插值，分割掩膜必须用最近邻插值，二者不要共用同一个插值器；③ 统一到目标间距时优先采用各向同性或接近各向同性的间距，并同步更新 affine；④ 做裁剪、翻转或加噪等增强后，方向与间距要一起校验，可用同一病例做“读—写—读回”往返测试；⑤ 对 PET 单独检查 SUV 单位与是否已完成衰减/散射校正，不要把未校正图像与已校正图像混在同一训练集；⑥ 把预处理脚本与随机种子纳入版本控制，任何间距或插值改动都视为一次新的基线。
  • 适用条件适用于三维体数据的分割、配准与多模态融合，包括 PET/CT、PET/MRI 与 SPECT/CT。该建议只解决“几何与强度表示是否一致”，不解决金标准是否可信；若重采样后的掩膜由单一医师目测勾画，指标仍只反映与该医师的一致程度。本期入选的铜陵市人民医院研究把 PET/CT 与操作 CT 融合后做切片级分割，其中跨模态配准与间距统一正是这类流程的前置条件；这属单篇研究的实践启发，不是已经形成共识的指南。
  • 常见误区只存像素数组、丢掉 direction，导致左右或前后翻转却仍能“看起来正常”；对分割掩膜使用线性插值后再按 0.5 阈值化，凭空制造或抹掉边界体素，使 Dice 虚高；把 CT 的 HU 窗宽窗位处理直接套用到 PET 的 SUV 上；重采样后忘记更新 affine，配准时偏移量看起来很小却在累积；把不同设备、不同重建协议的 SUV 差异当成真实生物学差异，进而得出“模型学到了生物学”的结论。
