鼻咽癌靶区自动分割：把肿瘤先验与勾画文本一起输入

鼻咽癌临床靶区（CTV）勾画耗时且观察者间差异大；现有自动分割只读图像，忽略了“高危/低危靶区范围如何外扩”这类由科室经验决定的规则。作者把三路信息一起送入模型：CT 图像、人工勾画的原发灶与转移淋巴结掩膜、以及由大语言模型从电子病历抽取的结构化勾画计划文本，用文本-图像交叉注意力融合，主干为多视角 UMamba，损失由 Dice、交叉熵与对比项组成。回顾性纳入 184 例鼻咽癌患者，144 例训练、40 例测试：高危 CTV 平均 Dice 0.892±0.035，低危 CTV 0.738±0.149，整体 CTV 0.889±0.024，95% Hausdorff 距离与平均表面距离同向改善。消融显示只用肿瘤信息或只用文本都能超过纯图像基线，但均不及二者联合。

  • 研究痛点CTV 边界是“解剖 + 科室外扩惯例”的复合判断，纯图像模型难以学到；低危靶区缺乏清晰影像边界，正是观察者间差异最大的部分。
  • 方法与数据CT + GTVp/GTVn 掩膜 + LLM 抽取的勾画计划文本 → 文本-图像交叉注意力 + 多视角 UMamba；单中心 184 例、144/40 划分；Dice、HD95、ASD 三项指标与两组消融基线。
  • 局限与迁移单中心、测试集仅 40 例，无外部医院验证；文本字段来自本院结构化病历，跨院复用需重建抽取模板；低危 CTV 的 Dice 只有 0.738，说明边界区域仍是瓶颈。迁移到 PET/CT 时，PET 代谢边界可作为第三路输入，但必须先验证 PET 与 CT 的配准误差如何影响靶区外扩，不能直接沿用 CT-only 的结论。

02

DaTscan SPECT 三分类：把 SWEDD 单独当作一类

帕金森病与其他帕金森综合征临床重叠，DaTscan SPECT 常用于辅助诊断，但一部分临床诊断患者的影像并无明显多巴胺能缺损（SWEDD），构成诊断灰区。作者用 PPMI 的 DaTscan 影像训练 AlexNet、EfficientNet-B0 与 ViT 三种骨干，做 PD / SWEDD / 正常三分类，并用嘉义基督教医院的独立队列做外部验证。EfficientNet-B0 在 PPMI 上三分类准确率 94.2%（ViT 92.0%、AlexNet 89.5%），外部验证准确率 92.4%、F1 95.8%；把最优模型封装为诊断 App 后，在区分 PD 与 SWEDD 合并组同正常对照时准确率为 90.6%。

  • 研究痛点二分类（PD vs 正常）会把 SWEDD 这个临床真实存在的灰区压进正常类，指标虚高而临床不可用；跨中心外部验证在核医学影像分类中仍少见。
  • 方法与数据PPMI 训练 + 单家外部医院验证；三种骨干在相同流程下对照；准确率、精确率、召回、F1；另做 App 封装并单独报告二分类结果。
  • 局限与迁移外部验证集规模未在摘要披露，且仅为单家医院；SWEDD 标签依赖随访后的临床复核，本身带标签噪声；App 的 90.6% 是 PD+SWEDD 对正常的二分类准确率，不能与三分类准确率直接比较。迁移到 PET/CT 时，SPECT 的半定量摄取比与 PET 的 SUV 口径不同，搬到 FDG 或 PSMA PET 前需重做强度归一化，并检查不同重建算法对分类边界的影响。

03

基础模型适配与从零训练：结论取决于是否跨院

论文以 DINOv2 作基础模型，比较从“只调 bias 项”到“全量微调”的一系列适配策略，与从零训练的 U-Net、ResU-Net 对照，任务覆盖结肠镜、乳腺超声与皮肤镜，既在同源留出集上测，也在其他机构的独立数据集上测。结果分成两层：在同源分布内且训练数据充足时，任务专用模型仍有竞争力、边界刻画更精细，而基础模型更常漏掉小病灶；在每一个外部数据集上，适配后的基础模型都更好。需要适配的参数量很小，所需容量由影像域决定，而不是由适配方法决定。作者还发现一个被广泛使用的息肉测试集与另一基准存在图像重复。

  • 研究痛点多数“基础模型优于专用模型”的结论只在训练分布内比较，且只用一个配置未经论证的专用基线，无法回答“换一家医院是否还成立”；需要适配多少容量也缺少系统实验。
  • 方法与数据DINOv2 + 由 bias-only 到全量微调的适配谱；U-Net / Res-U-Net 从零训练对照；结肠镜、乳腺超声、皮肤镜三类任务；同源留出集 + 多机构外部数据集；另做测试集重复图像核查。
  • 局限与迁移三类任务都是 2D 纹理型影像，没有 3D 体数据，也没有 PET；“外部更好”的结论未在低计数、强噪声模态上验证；重复图像只作为提示提出，未量化其对指标的影响。迁移到 PET/CT 分割时，“同源 + 多外部中心”的分层报告设计可直接借用，但需在 3D 体素与双模态输入上重跑，并注意切片级划分造成的患者内泄漏。

3D 自监督预训练：子体积怎么采比换主干更关键

3D 医学自监督预训练普遍用随机裁剪取子体积，隐含假设“所有空间位置同等值得观察”，但解剖先验与空间冗余让不同区域的信息量差别很大。作者先用受控的裁剪质量实验证明更好的子体积带来更好的下游迁移，把采样策略识别为被忽视的瓶颈，再提出 VolumeProbe：离线构建由解剖感知、信息量与多样性引导的粗到精子体积探针库来替换随机裁剪，可直接插入现有 3D 自监督流程。轻量 Lite 版只用几何与图像统计线索，诊断用 Feat 版使用冻结视觉特征；在多个 3D 自监督骨干与下游任务上，Lite 版稳定优于随机采样，作者进一步用解剖合理性、冗余度与表征结构解释增益来源。

  • 研究痛点预训练算力很大一部分花在“看哪里”这个几乎没人调的设计上；随机裁剪让模型反复看到空白或高度重复的区域，既浪费时间也削弱表征。
  • 方法与数据VolumeProbe 离线探针库 + 解剖感知、信息量、多样性三重引导；Lite（几何与统计线索）与 Feat（冻结特征）两种实例；多个 3D 自监督骨干与多个下游分割任务对照，并附机制分析。
  • 局限与迁移探针库离线构建，换数据集需重建，成本未与在线自适应方法比较；评测集中在 3D 分割，未覆盖检测、配准与分类；Feat 版依赖冻结特征质量，增益不如 Lite 稳定。迁移到 PET/CT 时，探针库需同时考虑 CT 解剖与 PET 摄取分布，否则可能把高摄取的正常器官误判为高信息区域。

多智能体做可控肿瘤合成：先判断缺哪种形态

扩散模型合成肿瘤可缓解数据稀缺，但缺少属性级可控、缺少闭环质检，也不知道目标分布里究竟哪种形态稀缺。MATS 把这件事拆给多个智能体：先对目标疾病的形态分布做属性级画像（几何与外观），据此生成“放大稀有亚型、保留常见亚型主导”的生成计划；再定位目标器官、提出解剖上合理的放置位置，分两阶段扩散分别生成肿瘤掩膜与纹理；全程在三个检查点校验属性对齐，不一致就反馈重生成。仅用单一来源的胰腺神经内分泌肿瘤数据训练，下游分割在域内以及跨 LiTS、KiTS、MSD-Pancreas 均稳定获益，而多数既有生成式增广方法在跨数据集时低于只用真实数据训练。

  • 研究痛点生成式增广常“看着像但不可控”，无法针对缺失亚型补数据；没有闭环验证时，合成样本可能把分布偏移带进训练集，反而拖累下游。
  • 方法与数据形态画像 → 生成计划 → 器官定位与放置 → 两阶段扩散（掩膜 + 纹理）→ 三检查点属性校验与选择性重生成；单源胰腺神经内分泌肿瘤训练，下游在 LiTS、KiTS、MSD-Pancreas 评测。
  • 局限与迁移只有单一病种与单一来源训练数据，“稀有亚型放大”的比例是启发式设定，未做敏感性分析；评价终点是下游分割增益，没有人读片或病理对照，合成病灶的真实性未被独立验证。迁移到 PET/CT 时，合成需同时生成 CT 纹理与 PET 摄取，且 SUV 分布要可核验；把合成数据投入训练前，建议先做合成与真实病灶的分布检验。

世界模型是否真的用上干预信息：一个可测量的检验

患者世界模型越来越多被当作临床试验模拟器，但能力等级一直靠读论文评定而非测量。作者把“反事实”这一级变成可测量量：从 30,119 项已公布结果的 II/III 期试验中构造 9,996 个组内对照（来自 7,207 项试验），并用“干预盲”参照模型——同样的模型、同样的试验，但隐去全部可识别干预的字段——来衡量模拟器的准确度有多少真正来自知道用了什么干预。在时间切分（655 项试验的 878 个对照）上，基于注册信息的梯度提升模拟器把误差降到朴素基线的五分之一，但干预技能为 −0.12（95% 置信区间 −0.21 至 −0.05）：隐去干预反而更准。只读注册方案的前沿语言模型干预技能为 0.20（0.08–0.31），更小与开源模型处在检测限附近。

  • 研究痛点“能预测结局”和“知道干预如何改变结局”是两件事，聚合误差无法区分二者；现有世界模型的能力分级缺少可复现的测量工具，容易把相关性当成可干预性。
  • 方法与数据注册试验回溯构造组内对照 + 干预盲参照模型 + 干预技能指标（全模型相对参照模型消除的误差）；时间切分、替代特征化、分层与同分子检索等稳健性检验；代码与数据开源并归档。
  • 局限与迁移单作者、workshop 报告，尚无期刊同行评审；数据是试验注册与结果摘要，不含影像与个体轨迹，结论不能直接外推到影像世界模型；“干预技能为负”也可能反映注册字段本身信息量不足。迁移到影像纵向队列时，这套“隐去干预再测”的对照设计可以照搬：先证明模型确实用上了治疗信息，再讨论预测精度。

07

上线前先做训练-测试近重复图像检查

本期的基础模型对照研究发现，一个被广泛使用的息肉测试集与另一基准之间存在图像重复。为什么重要：只要训练集与测试集共享少量近重复图像，Dice 与准确率就会被系统性抬高，而这类泄漏不会报错、也不出现在 loss 曲线上；对声称“外部验证”的论文，泄漏还会把“记性好”包装成“泛化好”，使基线和方法的比较失去意义。

  • 操作要点① 以患者或检查为单位划分训练与测试，不要以切片、图像或增强样本为单位；② 对两组图像做感知哈希（pHash/dHash）或 SSIM 阈值筛查，边界样本人工复核；③ 同时报告重复率与去除重复后的指标变化，两个数字都要给；④ 沿用公开基准前，先核对其与训练集是否同源；⑤ 把筛查脚本、阈值与命中清单放进仓库，便于他人复算。
  • 适用条件适用于任何以图像为单位的监督学习（分类、分割、检测），尤其是多数据集拼接与网络爬取数据；即使是单中心连续队列且已按患者划分，也建议跑一次哈希筛查确认。
  • 常见误区① 认为“来自不同数据集就是不同患者”，忽略同一批图像被多个基准重复发布；② 只用随机划分并报告单次结果；③ 把去除重复后的指标下降当成“模型变差”，而不是泄漏被纠正；④ 用文件级 MD5 代替感知哈希，漏掉重压缩、裁剪与插值后的近重复。
