自动关节分割让 FDG/NaF PET/CT 关节定量可标准化

用 PET 定量关节代谢与炎症时，关节边界在解剖上并不清晰，手工勾画既耗时又难以标准化。这套流程先用 TotalSegmentator 在 CT 上生成骨性结构分割，再按“相邻骨之间、落在设定距离阈值内”的规则推导出 30 个负重关节区域，从而在 PET/CT 上自动得到关节 ROI 并计算 SUVmean。数据为健康志愿者扫描（FDG 75 例、NaF 80 例），用 Pearson 相关分析关节摄取与年龄、BMI 的关系，并在每个示踪剂-协变量族内做 Benjamini-Hochberg FDR 校正。自动流程把单例分割时间从约 30 分钟降到约 1.5 分钟；同一参与者两次 PET/CT 检查各自独立生成的关节 ROI 高度一致（中位 r=0.98，中位 ICC 0.94）。FDR 校正后，NaF 摄取与 BMI 在胸段（T3-T6、T7-T8、T9-T11）和腰骶段（L5-S1）椎间盘、双侧骶髂关节、髋与膝关节正相关，与年龄在颈椎间盘（C1-C2、C3-C7）正相关；FDG 摄取与 BMI 在 C1-T6（T1-T2 除外）和 T9-S1 椎间盘、双侧骶髂关节、左髋与双膝正相关，与年龄在双膝正相关（均 q<0.05）。

  • 研究痛点关节 PET 定量依赖手工勾画，而关节边界缺少统一解剖定义，导致跨读片者、跨中心的定量结果不可比，且单例耗时约 30 分钟难以规模化。
  • 方法与数据TotalSegmentator 生成 CT 骨分割 + 几何规则导出 30 个负重关节 ROI；健康志愿者 FDG 75 例 / NaF 80 例；速度 30 分钟降至约 1.5 分钟；同一参与者两次扫描的关节 ROI 一致性中位 r=0.98、中位 ICC 0.94；相关分析经 Benjamini-Hochberg FDR 校正。
  • 局限与迁移队列为健康志愿者，不含患者或治疗随访数据，所得到的摄取-年龄/BMI 关联不能直接外推到疾病状态；作者明确指出，颈椎 NaF-年龄正相关出现在 SUVmean 与 ROI 体积明显相关的少数关节，属暂定结论；ROI 由 CT 骨分割加几何规则导出，在术后改变、骨性结构异常或严重骨质疏松时规则可能失效。迁移价值在于“先用通用解剖分割模型在 CT 上定位，再推导功能 ROI”这条低成本路径，可作为 PET/CT 器官级定量的可复现基线；本项目若做头颈 ROI 定量，需重新定义规则，并在患者数据上重复验证重测一致性与疾病状态下的稳定性。

多模态 PET-MR 分割：胶质母细胞瘤计划靶区与复发定义

胶质母细胞瘤主要依靠 MR 做诊断与治疗计划，O-(2)-18F-氟乙基酪氨酸（FET）PET 被推荐用于鉴别局部复发与放射性改变，但临床落地受三个因素制约：肿瘤与危及器官勾画耗时、PET 增值证据不足、设备可及性有限。研究用 nnU-Net 在 33 家机构 1,610 例患者的手工勾画上训练自动分割模型，以 Dice-Sørensen 系数评价；并在 185 例上用 Wilcoxon 符号秩检验、DSC 与放射组学特征评估 PET 与 MR 在复发定义上的互补性。测试集结果为 DSC(MR-增强) 0.76±0.24、DSC(MR-水肿) 0.69±0.23、DSC(PET-摄取) 0.71±0.20、DSC(计划靶区) 0.93±0.05、DSC(危及器官) 0.70±0.13。基于 MR 与基于 FET-PET 的复发勾画在体积（p=0.0497）与位置（DSC 0.45±0.20）上均存在显著差异。在 37 个于 MR∩PET 与 MR-Only 之间有显著差异的 MR 放射组学特征中，没有一个放射组学图能空间定位 PET 所见（阳性预测值与敏感度均 <0.6）。

  • 研究痛点PET/MR 联合在胶质瘤中的增值缺少大样本量化证据；肿瘤与危及器官仍需手工勾画，勾画成本限制了多模态流程进入常规临床。
  • 方法与数据nnU-Net 自动分割，训练自 33 家机构 1,610 例手工勾画；以 DSC 评价五类目标；185 例做 PET/MR 复发互补性分析（Wilcoxon 符号秩检验、DSC、放射组学特征，按 MR∩PET 与 MR-Only 分组比较）。
  • 局限与迁移PET 摄取区 DSC 0.71 且标准差达 0.20，提示小病灶与低摄取区稳定性有限；仅使用 FET 一种氨基酸示踪剂；互补性分析是回顾性影像比较，未与病理或生存终点对照；33 家机构的数据存在采集协议异质性，摘要未做分层报告。迁移价值：PET 与 MR 复发勾画 DSC 仅 0.45 这一量化结果，直接支持“不能把 PET 勾画当作 MR 勾画的替代”这一判断；本项目若联合 PET/CT 与 MRI，应把两种勾画的一致性单独报告，并在论文中明确互不替代。

原型记忆引导的 3D 网络做心肌灌注 SPECT 分割

心肌灌注显像是冠心病无创评估的常用手段，但适合可复现深度学习分割研究的公开数据很少。研究提出 CardioProto-SegNet：类 3D U-Net 的残差编码器-解码器，加入 squeeze-and-excitation 通道重标定，并在瓶颈处用 K=4 个可学习原型构成的轻量原型记忆做解剖细化。数据使用 PhysioNet 公开的心肌灌注显像数据库 v1.0.0（83 例，GE Discovery NM 530c CZT 探头，静息 99mTc-MIBI 方案），统一重采样到 48×64×64，损失为 BCE 0.35 与 soft Dice 0.65 加权，AdamW、batch 16、固定随机种子，五折交叉验证后在独立患者级留出测试集上只评估一次。五折平均 Dice 0.8239±0.0350、IoU 0.6870、PR-AUC 0.8561、HD95 2.5181；留出测试集 Dice 0.7402，相较 3D U-Net 与 Attention 3D U-Net 的 Dice 提升 +0.038 至 +0.055（Holm-Bonferroni 校正后显著）。消融显示移除残差连接下降最大（Dice 0.7448）。因公开数据无确诊缺血或梗死标签，作者另做了基于心肌 ROI 摄取异质性的探索性亚组分析。

  • 研究痛点心肌灌注 SPECT 的深度学习分割缺少可复现的公开数据基准，多数研究使用私有数据，结果难以复现与比较。
  • 方法与数据CardioProto-SegNet（残差 3D U-Net + SE 通道重标定 + 瓶颈处 4 原型记忆细化）；PhysioNet 心肌灌注显像数据库 v1.0.0，83 例，GE Discovery NM 530c CZT，静息 99mTc-MIBI；五折交叉验证 + 独立患者级留出测试；心肌前景体素仅约 1.54%。
  • 局限与迁移仅 83 例、单一公开数据集，无外部多中心验证；只有静息采集，缺少负荷-静息配对，无法支持完整灌注分析；无确诊缺血/梗死标签，报告的是纯图像分割性能而非冠心病诊断性能；前景体素占 1.54%，Accuracy 0.9943 属虚高指标；作者承认 Residual 3D U-Net 的 HD95 与 ASD 更低。迁移价值：可作为 SPECT 心肌分割的公开数据基线，其“原型记忆 + 患者级划分 + 折间标准差”的实验规范值得借鉴；但 PET 与 SPECT 的对比度形成机制不同，原型记忆的收益需在 PET/CT 上重新验证。

PET/CT 影像基因组学：多标签学习要看基因组合

靶向治疗依赖组织活检做突变分型，而活检有创且存在取样限制。研究用深度学习从 PET/CT 预测非小细胞肺癌的 EGFR、TP53 与 KRAS 突变，并系统比较“成对多标签联合学习”与常规单基因分类的效果差异。数据来自一个新建立的英国放射基因组学队列。结果显示：KRAS 与 TP53 联合预测把 KRAS 的 AUC 从 0.58 提升到 0.64、TP53 从 0.69 提升到 0.71；EGFR/KRAS 组合中只有 EGFR 从联合学习中获益，而 EGFR/TP53 组合未见改善。作者的结论是多标签学习的效果取决于所建模的具体基因突变组合，PET/CT 影像基因组学更宜按突变分别建模。

  • 研究痛点PET/CT 能否部分替代组织活检做无创突变分型缺少系统评估；同时“多标签联合训练一定更好”在影像基因组学中是一个未经量化的默认假设。
  • 方法与数据基于 PET/CT 的深度学习突变预测；比较成对多标签学习与常规单基因分类；英国放射基因组学队列（摘要未披露总例数与划分方式）；AUC：KRAS 0.58→0.64、TP53 0.69→0.71，EGFR/KRAS 仅 EGFR 获益，EGFR/TP53 无改善。
  • 局限与迁移预印本，尚未同行评审；摘要未披露样本量、数据划分与置信区间；AUC 0.58–0.71 属中等偏弱，远不足以支持替代活检临床决策；单一国家队列，无外部验证。迁移价值：对本项目最直接的可检验结论是方法论层面的——把多终点联合训练当作默认增益是有风险的，做多终点 PET/CT 预测时应先按终点拆分做消融，再决定是否联合建模。

CNN 基于 FDG PET/CT 术前鉴别卵巢肿瘤良恶性

盆腔肿块的良恶性最终依赖术后病理，术前影像判读存在主观性。研究纳入 2020 年 1 月至 2023 年 12 月术前接受 18F-FDG PET/CT 的 101 例盆腔肿块患者，按组织病理结果分为良性与恶性组，用 ResNet-18 与一个结构更简单的 CNN 两个模型做分类，并用 Grad-CAM 显示模型做出判断时主要依据的图像区域。ResNet-18 的准确率为 0.882、AUC 0.938、敏感度 0.829、特异度 0.913；简易 CNN 的准确率为 0.876、AUC 0.957、敏感度 0.761、特异度 0.942。作者认为结果显示了基于 PET 的深度学习肿瘤分类在术前鉴别诊断中的潜力。

  • 研究痛点术前良恶性判断依赖主观读片，确诊要等术后病理，缺少可在术前复用、且能给出可视化依据的客观影像模型。
  • 方法与数据101 例单中心回顾性队列，术前 18F-FDG PET/CT，病理为金标准；ResNet-18 与简易 CNN 两个模型对比；以准确率、AUC、敏感度、特异度评价，并用 Grad-CAM 做归因可视化。
  • 局限与迁移单中心 101 例，样本量小且无外部验证；摘要未说明训练/测试划分方式、良恶性比例与置信区间；输入形式（二维切片还是三维体积、是否裁剪至病灶）在摘要中未明确，复现存在实质障碍；区间估计的缺失使 AUC 0.938 与 0.957 的差异无法解释。迁移价值有限但方向明确：可作为“PET/CT 二分类 + 归因可视化”的最小可复现模板，用于搭建实验流水线；迁移到头颈任务必须重新训练并补充外部队列与置信区间。

基础模型嵌入替代放射组学预测头颈癌远处转移

早期预测头颈癌远处转移风险有助于及时干预，但多数机器学习方法依赖肿瘤分割等先验 ROI，既需要专家标注、耗时，又引入操作者间差异。研究使用 RADCURE 数据集中 2,327 例患者的术前 CT，构建三套特征——放射组学特征、深度学习特征、CT 基础模型派生特征，分别输入多层感知机预测远处转移风险；用五折交叉验证选模，在留出测试集上评估。CT 基础模型嵌入的 AUC 为 0.791，优于放射组学的 0.772 与深度学习的 0.753，与“放射组学 + 深度学习”联合特征模型的 0.794 基本持平。作者认为，基础模型特征能在几乎不需要预处理与专家标注的前提下，提供可替代传统放射组学的选项。

  • 研究痛点影像预后建模普遍依赖人工分割 ROI，标注成本与操作者间差异限制了可复现性与跨中心规模化。
  • 方法与数据RADCURE 2,327 例术前 CT；三套特征（放射组学 / 深度学习 / CT 基础模型嵌入）分别接入 MLP；五折交叉验证选模、留出测试集评估；AUC：CT 基础模型 0.791、放射组学 0.772、深度学习 0.753、放射组学+深度学习 0.794。
  • 局限与迁移预印本，尚未同行评审；模态为 CT 而非 PET/CT，疾病为头颈癌而非鼻咽癌，摘要未报告鼻咽癌亚组结果；0.753 至 0.794 的 AUC 差异缺少置信区间与统计检验，不宜解读为显著优势；仅单一公开数据集，无外部验证。迁移价值：对本项目最直接的可检验假设是——在鼻咽癌 PET/CT 上，用通用基础模型嵌入替代人工 ROI 放射组学，能否在保持 AUC 的同时省去分割标注；这是需要在 PET/CT 数据上从头验证的研究假设，不能把 CT 上的结果直接外推。

以 MedSAM 为代表的提示式分割基础模型在零样本与少样本下跨域表现良好，但其性能依赖提示质量与针对特定数据集的适配。研究系统比较六种适配策略：全模型与仅编码器的 LoRA、浅层与深层视觉提示微调（VPT）、仅解码器与全量微调。模型在 ISIC 2018 上训练，在干净提示与逐级加噪提示下评估域内与分布外数据：近 OOD 的 PH2（皮肤镜）、远 OOD 的 BUSI（乳腺超声）与 CBIS-DDSM（筛查钼靶）。结果显示，适配提升域内与近 OOD 表现，却常常降低远 OOD 表现；全量微调给出最好的折中，仅编码器 LoRA 是参数高效方案中最强的一种，在远 OOD 漂移下优于标准 LoRA 与 VPT。用中心核对齐（CKA）分析发现，远 OOD 退化与解码器表征漂移强相关，仅靠编码器相似度无法解释鲁棒性——仅编码器 LoRA 更稳的原因在于它既让编码器适应视觉特征分布变化，又保留了解码通路。作者还发现，在提示框上加入 0–100 像素随机抖动，能训练出更鲁棒且表现更好的模型。

病灶感知神经算子：CT 合成 PSMA PET 的定量保真

从 CT 或 MRI 合成 PET 有望降低给药剂量与设备占用，但现有方法多用 L1 或 MSE 等全局损失，对所有体素一视同仁。在全身 PSMA-PET 中，肿瘤体素占比极小却承载着临床相关的活度信号，因此模型可以在 SSIM 与 PSNR 很高的同时低估病灶活度或丢失肿瘤特异结构。放射组学能提供有生物学意义的强度与纹理描述，但直接从勾画好的病灶区提取特征、再做条件化，成本高且难以规模化。研究提出 LAFNO（病灶感知自适应傅里叶神经算子），用两个从 CT 高效计算得到的代理通道替代高维放射组学条件——对比度代理刻画局部密度变化、紊乱度代理刻画局部纹理异质性，注入模型瓶颈；并把全容积重建与病灶级总病灶活度（TLA）、肿瘤核心对比度、瘤周监督结合起来。在 TCIA PSMA-PET-CT-Lesions 数据集上与四种基线架构比较，LAFNO 在全图质量上保持竞争力（18F-PSMA 的 SSIM 0.960、68Ga-PSMA 的 0.938），同时把每例 TLA 误差降到 48.3% 与 64.0%，并在两种示踪剂、全部特征类别上取得最高的肿瘤核心放射组学可重复性；瘤周可重复性仍依示踪剂而异。

  • 研究痛点合成 PET 研究中常用的全图指标与临床关心的病灶定量脱节；而基于放射组学的条件化需要先有病灶勾画，难以规模化。
  • 方法与数据LAFNO = 傅里叶神经算子 + CT 派生的对比度/紊乱度双代理通道 + 全容积重建与病灶级 TLA、肿瘤核心对比度、瘤周监督联合训练；TCIA PSMA-PET-CT-Lesions 数据集；与四种基线架构比较；SSIM 0.960 / 0.938，TLA 误差 48.3% / 64.0%。

先按问题结构选指标：小目标分割不要把 Accuracy 当主指标

验证指标不是通用的工具箱。同一份模型输出用不同指标评价会给出完全不同的排名，Nature Methods 这篇方法学论文系统梳理了影像分析验证中的指标陷阱，核心主张是“指标必须与待解决的问题结构相匹配”：先确定评价单元是逐像素、逐实例还是逐对象，再决定用重叠类指标（Dice、IoU）、距离类指标（HD95、平均表面距离）还是检出/计数类指标，并同时报告类别不平衡情况与不确定度。本期收录的心肌 SPECT 分割研究正好提供了直观对照——心肌前景体素仅约 1.54%，模型的 Accuracy 高达 0.9943，而同一批数据的 Dice 只有 0.8239；只看 Accuracy 几乎无法区分模型好坏。

  • 操作要点① 先画问题结构图：评价单元是什么、前景体素占比多少、漏检与假阳性的代价是否对称；② 主指标选与临床或科研决策直接相关的那一类，病灶分割建议以 Dice 加 HD95 或平均表面距离为主，检出类任务另报每例假阳数与敏感度；③ 必须在论文中报告前景占比与类别基线，Accuracy 与 ROC-AUC 只作辅助指标；④ 用 bootstrap 或折间标准差给出置信区间，不要只报点估计；⑤ 把指标选择写进实验记录或预注册，避免事后按结果挑选指标。
  • 适用条件适用于医学影像分割、检测与定量验证，包括 PET/CT 病灶分割、SPECT 心肌分割、以及合成图像的病灶级定量评价（如总病灶活度误差与放射组学可重复性）。不适用于前景占比高、类别大致均衡的大器官或解剖结构分割——这类场景下 Accuracy 的信息量反而更高。
  • 常见误区一是把 Accuracy 或 AUC 当作小目标分割的主指标，在前景占 1% 量级时它们几乎恒等于 1，对模型差异完全不敏感；二是不报告前景占比与类别基线，让读者无法判断指标数值的含义；三是把 Dice 的提升直接解释为临床获益——Dice 改善可能全部来自大病灶，小淋巴结或低摄取灶的漏检没有任何变化，应按病灶体积或摄取强度分层报告；四是拿同一个测试集反复比较后再挑最优指标上报，这等同于隐形的过拟合。
