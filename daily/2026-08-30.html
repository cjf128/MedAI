PET 引导 SPECT：PSMA 治疗前后双中心病灶自动分割

转移性去势抵抗性前列腺癌患者接受 177Lu-PSMA 放射性配体治疗时，需要逐病灶手工分割才能提取体积与剂量学生物标志物，但手工分割在高度转移患者身上尤其耗时、难以规模化。这项双中心回顾性研究用 nnU-Net 训练了四种模型：仅 PET/CT（M1）、仅 SPECT/CT（M2）、PET/CT 与 SPECT/CT 联合训练而推理时单模态输入（M3）、以及把 PET/CT 分割结果作为先验输入通道的 SPECT/CT 模型（M4）。73 例患者每例都配对了治疗前的 68Ga-PSMA PET/CT 与第一周期治疗中的 177Lu-PSMA SPECT/CT，全部由四名核医学医师共识手工分割；模型先在亨利·贝克勒尔癌症中心 48 例上训练与内部验证，再在全队列重训后于南特大学医院 25 例上做外部验证。PET/CT 分割上 M1 与 M3 表现相当；SPECT/CT 上以 PET 为先验的 M4 最好。

  • 研究痛点PSMA 治疗前后需要跨模态的逐病灶分割以计算体积与剂量指标，但 SPECT 空间分辨率较低，单独分割精度不足，手工勾画难以规模化。
  • 方法与数据四种 nnU-Net 变体（PET/CT、SPECT/CT、联合训练、PET 分割作为先验）；73 例双中心配对 68Ga-PSMA PET/CT 与 177Lu-PSMA SPECT/CT（48 训练 / 25 外部）；四名医师共识标注。PET/CT：M1 内部 DSC 0.83±0.19、外部 0.76±0.22，M3 内部 0.83±0.16、外部 0.77±0.21。SPECT/CT：M4 内部 DSC 0.63±0.24、外部 0.78±0.14（PPV 0.65±0.26 / 0.75±0.23）；与 SPECT-only 的 M2 相比内部差异不显著（DSC p=0.35）、外部显著（DSC p=0.014）。
  • 局限与迁移回顾性设计、样本量仅 73 例且外部队列 25 例，置信区间较宽；靶向前列腺癌 PSMA 病灶，与鼻咽癌 FDG 病灶在分布与对比度上不同；作者团队含西门子 Healthineers（商业参与）。迁移价值在于「用高分辨率模态的分割结果作为低分辨率模态的先验」这一可复用设计，但迁移到本项目需在头颈数据上重训，并统一配准、分割口径与示踪剂方案。

不确定度增强的全身 PET/CT 病灶分割

全身 PET/CT 病灶勾画在临床上本就困难：病灶特征细微、存在混淆性摄取，读片者之间也有差异；现有深度学习分割还叠加了训练随机性、预测不一致、高肿瘤负荷病例漏检，且普遍不提供不确定度量化，临床难以判断哪些结果可信。研究以 nnU-Net 为基线，提出三层不确定度感知框架：用贝叶斯集成抑制训练随机性；做体素级认知不确定度与偶然不确定度分解；再用认知不确定度增强训练来提升病灶检出。训练与评估使用 AutoPET-III（1,611 例）与 Deep-PSMA（200 例）两套公开数据集，涵盖 FDG 与 PSMA 多种示踪剂与多癌种。作者称这是首个系统研究多示踪剂、泛癌种 PET/CT 分割不确定度量化，并把贝叶斯集成与不确定度感知建模结合起来的工作。

  • 研究痛点分割模型缺少不确定度输出，假阳性与漏检无法预判；训练随机性导致同配置复现结果不稳定，临床可靠性受限。
  • 方法与数据nnU-Net 基线 + 贝叶斯集成 + 体素级认知/偶然不确定度分解 + 认知不确定度增强训练 + 病例自适应路由；AutoPET-III 1,611 例与 Deep-PSMA 200 例。在未见 AutoPET-III 测试集上贝叶斯集成优于确定性 nnU-Net；不确定度图与误分类（尤其假阳性）区域相关；不确定度增强训练提升病灶召回但 FPVol 上升，呈精确率-召回权衡；病例自适应路由在基础与增强模型间选择可进一步提高 Dice。
  • 局限与迁移预印本，摘要未披露完整统计检验与置信区间；AutoPET-III 为挑战赛数据集，其成绩不等同外部临床验证；路由策略本身需要阈值选择，存在过拟合风险。迁移价值：把「不确定度图作为假阳性筛查线索」纳入 PET/CT 分割的人工复核流程是一条低成本路径，但阈值与路由规则需在头颈数据上重新校准。

PSMA-1007 PET 深度学习评分的多队列外部验证

根治性前列腺切除术前需要能稳定预测生化复发风险的影像标志物，而单靠 D'Amico 临床风险分层区分度有限。这项回顾性研究纳入 697 例术前接受 [18F]PSMA-1007 PET/CT 的前列腺癌患者，来自同一医疗网络的三个院区：庆春 445 例作训练、余杭 190 例作验证队列 1、之江 62 例作验证队列 2。研究训练五个卷积神经网络预测 3 年生化复发，把最优网络输出定义为深度学习评分（DLS），再比较四种术前模型：DLS 单独、D'Amico 单独、D'Amico 加 SUVmax、D'Amico 加 SUVmax 加 DLS。评价采用 Harrell C-index、逆概率删失加权的时间依赖 AUC、校准、决策曲线分析与嵌套模型比较。

  • 研究痛点术前缺少可稳定外推的影像定量标志物；单一临床分层对生化复发风险的区分度不足，且缺少校准与决策曲线层面的验证。
  • 方法与数据697 例三院区（训练 445 / 验证 1：190 / 验证 2：62），术前 [18F]PSMA-1007 PET/CT；五选一 CNN 产出 DLS，VGG19 固定时间分类最优，3 年 ROC AUC 分别为 0.834 / 0.755 / 0.723；整合模型 C-index 0.846 / 0.806 / 0.774，36 个月 AUC 0.853 / 0.801 / 0.779，优于 D'Amico 单独与 D'Amico 加 SUVmax；中高危 D'Amico、SUVmax 与 DLS 在多因素分析中均独立相关。
  • 局限与迁移回顾性设计，三个院区同属一个医疗网络，不等同独立机构的外部验证；仅覆盖前列腺癌与 PSMA-1007；终点为生化复发而非总生存；DLS 的可解释性未展开。迁移价值在于「影像深度学习评分 + 临床分层 + SUVmax 三段整合」与逆概率删失加权时间依赖 AUC 的评价流程，可直接用于 PET/CT 预后建模，但头颈任务需重新训练并按机构分层复核。

CLEAR：以临床概念为基石的可审计放射学基础模型

医学影像解释模型长期受限于黑箱性质：既难以获得临床信任，也难以在性能退化时定位原因。研究提出 CLEAR（Concept-Level Embeddings for Auditable Radiology），在 239,391 名患者的逾 87 万对影像-报告对上训练，学习视觉表征并把胸片投影到一个由大语言模型嵌入定义的语义丰富空间，使得每一次预测都能分解为各条放射学观察的加权贡献。在美国、欧洲与亚洲四个医师标注的大型数据集上做外部验证，CLEAR 不仅取得当前最优的分类性能，还支持三类应用：可审计的零样本病理检出、系统识别放射学混杂因素、以及从数据驱动概念构建专家级概念瓶颈模型。

  • 研究痛点黑箱模型无法解释「为什么对、为什么错」，性能退化与混杂因素难以定位，限制了审计与安全部署。
  • 方法与数据影像-报告对对比式预训练 + 大语言模型嵌入定义的临床概念空间；873,342 对影像-报告、239,391 名患者；四个来自美国、欧洲、亚洲的医师标注数据集外部验证；覆盖零样本检出、混杂因素识别与概念瓶颈模型三类应用。
  • 局限与迁移模态为二维胸片，与三维 PET/CT 在分辨率、通道结构与任务形态上差异明显；概念空间源自报告文本，会继承报告书写与标注偏差；未在分割或肿瘤负荷量化任务上验证。迁移价值：把预测分解为可检视的概念贡献，可用于本项目多中心 PET/CT 建模前的混杂因素排查——这是研究假设，必须在 PET/CT 数据上重新验证。

Rad-JEPA 3D：面向三维 CT 的联合嵌入预测预训练

三维医学影像自监督预训练是无标注数据利用的核心手段，但现有体数据编码器常常丢失下游推理所依赖的粗粒度空间与几何结构，限制了器官解耦、异常检出，以及与语言模型配合时的空间理解能力。研究提出 Rad-JEPA 3D：从掩码视图预测完整扫描的潜特征。其核心是混合 H-Mamba 编码器——Mamba 状态空间分支通过序列扫描建模层间连续性，分组查询注意力分支捕捉跨平面空间上下文，两者经轻量 per-token 路由融合；另提出隐状态正交正则化（HSOR），对齐师生隐状态以降低整条编码器的特征冗余。模型在约 12 万例 CT 扫描上预训练，总参数 4.0B。

  • 研究痛点三维自监督编码器保不住体数据的空间与几何结构，导致下游空间推理与器官解耦能力不足，只能靠扩大语言模型规模弥补。
  • 方法与数据联合嵌入预测 + H-Mamba 混合编码器（Mamba 分支 + 分组查询注意力分支 + per-token 路由）+ 隐状态正交正则化；约 120,000 例 CT 预训练，总参数 4.0B；在封闭式 VQA 上达到与最优方法可比的水平，在 Spatial-Med 基准上取得最佳平均空间推理分数；消融确认混合块与 HSOR 增益互补。
  • 局限与迁移预印本；仅覆盖 CT，不含 PET 或 PET/CT；评测以视觉问答与空间推理为主，未在病灶分割或肿瘤负荷量化上验证；4.0B 参数与 12 万例预训练规模对复现算力要求较高。迁移价值：三维自监督预训练与显式空间结构保持，是 PET/CT 三维表征学习可借鉴的路线——属研究假设，需在 PET/CT 数据上重新预训练与验证。

无标签的基础模型选择：分布漂移下用伪标签分歧排序

基础模型部署到新机构时性能差异很大，而目标域标签通常拿不到，无法直接比较候选模型，只能退而按源域留出精度排序。研究在 SUDO（无需真值标注评估临床 AI 系统的框架）基础上提出无标签选择准则：按预测概率把无标签目标域数据分区，逐区度量反映类别污染的伪标签分歧，聚合后得到 AURCC 分数，全程不需要目标域标注，也不需要微调。作者在胸片分类的三种院间漂移场景下，对 BioMedCLIP、CXR-CLIP、CheXzero、MedCLIP、MedImageInsight、CLIP 六个视觉-语言模型排序，覆盖零样本与 MLP 探针两种设置。

  • 研究痛点目标域无标签时无法判断哪个候选基础模型更合适，而按源域精度排序在标注稀缺场景下并不可靠。
  • 方法与数据基于 SUDO 的伪标签分歧分区度量 AURCC；胸片分类的三组院间漂移场景；六个视觉-语言模型，零样本与 MLP 探针两种设置。AURCC 排序与真值排序的 Spearman rho 最高 0.943（p<0.05）；与「按源域留出精度排序」这一自然基线相比，源域标注量大时相当，源域标注量小时更准确。
  • 局限与迁移预印本；仅在二维胸片分类与视觉-语言模型上验证，未覆盖分割任务或 PET/CT 模态；方法假定类别污染程度与排序误差相关，该假设在病灶级任务上是否成立未经验证。迁移价值：为「多中心 PET/CT 该选哪个公开基础模型」提供了无需目标域标注的排序思路——这是研究假设，必须先在 PET/CT 数据上验证。

RIDE：TNM 可问责的全身 PET/CT 报告起草

全身 18F-FDG PET/CT 是肺癌分期的核心手段，但报告起草既耗时又容易出错——一处定位错误就可能改变 TNM 分期与治疗决策。研究把 PET/CT 报告起草重新定义为「TNM 可问责的决策支持」，提出两阶段双模态三维框架 RIDE：第一阶段从配对的 PET 与 CT 体数据生成面向 TNM 的结构化印象；第二阶段做分层器官级范例检索，并提示大语言模型在这些可检视的中间产物条件下合成完整的 Findings 与 Impression。数据在 3 家医院 1,583 例因疑似或确诊肺癌转诊的全身 FDG PET/CT 上构建，留出测试集 520 例，其中 276 例来自 2 家独立机构的外部病例。

  • 研究痛点通用大模型直接生成报告缺乏可检视的中间依据，一处定位错误即可改变分期与治疗决策，且跨站点泛化未经验证。
  • 方法与数据两阶段双模态三维框架（TNM 结构化印象生成 → 器官级范例检索 → 条件化报告合成）；3 家医院 1,583 例全身 FDG PET/CT，留出测试 520 例（含 2 家独立机构 276 例外部病例）。外部集上临床依据的能力指标提升 +20.4；医师 Likert 评分内部 4.00、外部 4.17；在受评基线中 TNM 分期性能最佳。
  • 局限与迁移回顾性研究，作者明确需前瞻性研究进一步刻画真实工作流效用；参照标准为临床报告而非前瞻判读金标准；外部病例来自 2 家机构且限于肺癌队列。迁移价值：「先结构化、后生成」加「器官级范例检索 + 可检视中间产物」的分解式 Agent 设计，是本项目影像科研 Agent 可直接借鉴的架构；迁移到鼻咽癌需重建器官与靶区范例库，并复核 T/N 分期口径。

BaT：用阶段评分规则自演进的医学科研 Agent

长程 Agent 已开始自动化产出代码、报告与研究产物，但医学影像工作流是多阶段且数据敏感的，专家轨迹稀缺、难以共享。结构化基准能用阶段级评分规则定位失败，标准后训练流程却会在下一轮训练前丢弃这些诊断信息。研究提出 Benchmark-as-Teacher（BaT）这一递归自我改进系统，包含两个联动组件：在策略更新循环之外合成内容隔离训练状态的异步 Stage Bank 数据流水线；以及自改进后训练方法 BiCuRL（双层课程强化学习）——用固定留出评测选择下一阶段课程，用任务评分规则校验 rollout，以 GRPO 更新策略，再把候选检查点送回评测。

  • 研究痛点医学影像科研工作流的专家轨迹稀缺，而基准给出的阶段级失败诊断没有被回流到训练环节。
  • 方法与数据异步 Stage Bank 数据流水线 + BiCuRL 双层课程强化学习（留出评测选课程、评分规则校验 rollout、GRPO 更新、检查点回流）；在 AutoMedBench-Lite 上评测，BaT-4B 与 BaT-9B 的 Overall 分数较各自 Qwen Instruct 基线翻倍以上，BaT-9B Agent 达 79.6 Overall，高于 Claude Code 配合下 Claude Opus 4.6 的 77.5。
  • 局限与迁移预印本；分数来自单一基准 AutoMedBench-Lite，基准分数不等于真实科研产出质量，也未披露具体影像任务的细分错误分析；作者含 NVIDIA（商业参与），模型与算力依赖需标注。迁移价值：「用阶段级评分规则做课程选择与 rollout 校验」可用于本项目影像科研 Agent 的训练与审计流程设计——这是研究设想，需在本项目任务上自建评分规则并验证。

CalTwin：用 Fisher 信息正则化校准医学世界模型

医学世界模型的目标是学习患者或器官生理的潜状态，以及描述该状态在干预下如何演化的转移函数。研究指出两类威胁可靠性的失效模式：一是协变量漂移——训练数据按医院、扫描仪与时间被切碎，潜动态预测器在各片段看到的分布既彼此不同、也与部署时不同；二是置信度错位——多步预测往往恰在临床风险最高处过度自信。作者主张两者可以用同一个轻量正则化目标统一处理，即 CalTwin：把基于 Fisher 信息的漂移惩罚与置信度错位惩罚结合，施加于 GRU 医学世界模型的潜状态转移预测器，并推导了合并目标，说明哪些证明步骤可从分类设置直接迁移、哪些需要改写。

  • 研究痛点多中心碎片化数据造成协变量漂移，多步预测的置信度又在高风险处失准，两者都会削弱世界模型在临床部署中的可信度。
  • 方法与数据Fisher 信息漂移惩罚 + 置信度错位惩罚的统一正则化，施加于 GRU 潜状态转移预测器；在 PhysioNet 2019 脓毒症挑战赛上评估，两个医院系统作为顺序训练片段，未见系统作为分布外测试。相对无惩罚基线，分布外下一步潜状态 MSE 降低 9.1%（FIM 惩罚单独贡献 7.0%）；ECE 下降存在但幅度很小（CalTwin 0.7%、单独使用置信度惩罚 1.3%）。
  • 局限与迁移预印本；实验用 ICU 时间序列而非医学影像，不含影像模态；潜状态 MSE 与 ECE 均为代理指标，未验证下游临床决策收益；校准收益很小，作者未宣称已解决该问题。迁移价值：把多中心碎片化视为「顺序训练片段」并对抗协变量漂移的建模方式与本项目多中心 PET/CT 的问题结构同构——这是研究假设，必须在 PET/CT 数据上重新验证，且目标函数需替换为影像状态预测任务。

PETHarmony：跨扫描仪与示踪剂的 PET 体素级一致性化

PET 定量在肿瘤、神经科学与临床中广泛应用，但扫描仪、采集协议与示踪剂差异带来的系统性变异会削弱多中心研究的可靠性。研究提出 PETHarmony：用线性神经网络建模协变量，再用奇异值分解在体素空间隔离并移除变异。验证分四个场景：25 例配对的 18F-FBB PET/CT 与 PET/MR（华山医院）检验扫描仪变异移除；20 次 NEMA NU-2 IQ 体模重复采集验证绝对定量准确性；GAAIN 46 例与 OASIS 84 例配对 18F-FBP 与 11C-PiB 扫描评估皮层 SUVR 的跨示踪剂一致性；ADNI 471 例非配对多中心数据（18F-FBP、18F-FTP、18F-FDG）评估对阿尔茨海默病分类的影响。一致性化过程统一采用留一交叉验证，或在非配对数据上训练后应用于配对数据。

  • 研究痛点扫描仪、协议与示踪剂差异引入的系统性体素级变异，使多中心 PET 定量结果不可直接比较。
  • 方法与数据线性神经网络建模协变量 + 奇异值分解在体素空间去变异；四场景验证（配对 PET/CT-PET/MR 25 例、体模 20 次、GAAIN 46 例与 OASIS 84 例跨示踪剂、ADNI 471 例非配对多中心）。体素级 PET/CT 与 PET/MR 差异由 P<0.05 降至不显著；体模恢复系数曲线恢复并贴近参考线；跨示踪剂回归 GAAIN 由 y=0.52x+0.52（R²=0.89）改善至 y=0.93x+0.13（R²=0.97），OASIS 由 y=0.51x+0.55（R²=0.87）改善至 y=0.95x+0.06（R²=0.95）；多中心 AD 分类准确率提升 15.3% / 18.3% / 21.7%（分别对应 18F-FBP、18F-FTP、18F-FDG）。
  • 局限与迁移全部验证队列为脑 PET 与神经退行性疾病，未在肿瘤 PET/CT、病灶分割或肿瘤负荷量化上验证；方法假定变异可由线性协变量模型刻画，强非线性站点效应可能残留；跨示踪剂一致性化需要配对数据或共同参考分布。迁移价值：提供了一套「体模 + 配对 + 非配对多中心」三档验证范式，可作为本项目多中心 PET/CT 一致性化的现成参照，但需重建协变量集并重新验证。

RIMD：SPECT 心肌灌注无 CT 衰减校正

深度学习有望让 SPECT 心肌灌注成像在不依赖解剖信息或 CT 衰减图的情况下完成衰减校正，但泛化能力是关键。研究提出重建知情多域（RIMD）框架：把三种 OSEM 重建设置下的多输入非衰减校正（NAC）图像一起送入模型，并采用衰减图域损失与衰减校正域损失的联合监督。SwinUNETR 在归一化 NAC 图像上以一致的五折交叉验证训练。数据为两个中心 1,058 例 99mTc-Sestamibi SPECT/CT 心肌灌注扫描，934 例训练、124 例作外部测试；评价涵盖衰减图域与衰减校正域的体素级与区域级指标、17 节段极坐标图分析、器官特异性分析，并在外部数据集的一部分上做了临床验证。

  • 研究痛点无 CT 场景下 SPECT 衰减校正必须纯数据驱动，但既往方法跨中心泛化未得到充分验证。
  • 方法与数据多重建设置多输入 + 衰减图域与衰减校正域双损失联合监督的间接策略，SwinUNETR 五折交叉验证；两中心 1,058 例（训练 934 / 外部测试 124）。衰减图 MRAE% 内部 25.02±23、外部 26.31±14；衰减校正图像 MRAE% 内部 11.72±6.3、外部 19.31±4.9；17 节段极坐标图 MRAE% 内部 5.04±4.6、外部 10.88±7.3；消融中显著优于直接与间接对照方法，外部子集临床验证显示高度一致。
  • 局限与迁移任务为心脏 SPECT 衰减图预测这一回归任务，不是病灶分割或分类；外部测试集仅 124 例；外部集误差明显放大，提示仍需按站点校准；未评估对下游灌注定量诊断结论的影响。迁移价值：「多重建设置多输入 + 双域联合监督」可用于 PET 衰减图或定量校正类任务，但需更换重建协议、评价指标并重新验证。

PET/CT 定量研究前，先核对 Units、SUV Type 与 Decay Correction 三个字段

PET 图像的像素值不等于 SUV。DICOM PS3.3「PET Information Module Definitions」把 Units (0054,1001) 定为 1 类（必须存在）字段，用于说明像素值单位；SUV Type (0054,1006) 为 3 类字段，枚举的归一化方式包括 BSA（体表面积）、BW（体重）、LBM（James 法瘦体重）、LBMJAMES128、LBMJANMA 与 IBW（理想体重）；Decay Correction (0054,1102) 同样是 1 类字段，说明本序列图像衰变校正所参照的真实事件，定义词为 NONE、START（采集开始时间，即 Acquisition Time (0008,0032)）与 ADMIN（放射性药物给药时间，即 Radiopharmaceutical Start Time (0018,1072)）。标准还说明，衰变校正所参照的时间可由 Decay Factor (0054,1321)、Frame Reference Time (0054,1300)、Radionuclide Half Life (0018,1075) 与 Series Date/Time 推导。

  • 操作要点逐例读取并落库 Units、SUV Type、Decay Correction、Radionuclide Half Life、Radiopharmaceutical Start Time 与 Acquisition Time，作为数据表固定字段；按 Units 与 Decay Correction 做分层统计，并在论文中附站点与协议分布表；数据划分按站点或扫描仪分层，优先做站点外验证，避免同一患者多次检查跨集泄漏；不要直接把像素值当 SUV，需要时按字段显式换算并注明归一化方式；把字段缺失或相互冲突的病例单列审查，不要静默丢弃。
  • 适用条件适用于 FDG、PSMA 等全身 PET/CT 的分割、检测与肿瘤负荷量化研究，包括本期 PET 引导 SPECT 分割、PSMA-1007 深度学习评分与 PETHarmony 一致性化等场景；SPECT 的定量体系与校正流程不同，需参考对应定量程序指南；若数据已由厂商导出为 SUV 且字段完整一致，仍应在抽样病例上核对单位与归一化方式。
  • 常见误区一是把 DICOM 像素值直接当作 SUV 使用；二是忽略 Decay Correction 的 START 与 ADMIN 差异，把衰变校正参照点不同的数据混在同一训练集里；三是只在训练前做一次性检查，没有把字段纳入数据划分与分层报告；四是以为做了强度归一化就等价于解决了协议差异——归一化只改变分布尺度，无法修正单位口径或衰变校正参照点的错误。这类偏差不会体现在 Dice 上，却会直接污染 MTV、TLG 与 SUVR 等量化指标。
