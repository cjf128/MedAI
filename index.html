MedPlex：视觉-语言协同适应的临床医学分割框架

医学图像分割在很大程度上仍被视为纯视觉问题，而临床解读往往依赖解剖结构、位置、外观与周边环境的文本知识。现有视觉-语言模型（VLM）范式下的文本引导分割方法通常仅将语言用作后期条件信号，限制其对视觉表征学习的影响。研究提出 MedPlex（Medical Plexus of Vision and Language），一个端到端 VLM 框架，使文本引导成为分割学习中持续、具临床依据的组成部分：通过双向融合（Bi-Fusion），视觉与文本表征在编码层级上共同演化；并引入类级与区域级概念对齐，在互补粒度上组织共享表征——类级对齐将每个解剖目标锚定到聚合的临床概念画像，区域级对齐通过类特异视觉证据保留形状、位置、外观与纹理等个体概念。语言由此在整个编码器中提供结构化监督，而非仅作为后期提示。MedPlex 在 CT 与 MR 的多器官、心脏亚结构与肿瘤分割基准上取得最优性能，包括使用真实自由文本临床监督的设置。

KANResDiff：KAN 局部残差扩散处理模糊医学分割

模糊医学图像分割旨在提供一系列多样但合理的分割假设，然而现有方法以固定且预定义的方式引入随机性，未能形成渐进式语义建模过程。研究提出 KANResDiff，用 Kolmogorov-Arnold 网络（KAN）学习局部残差扩散，从而为各阶段分配不同角色进行模糊建模：独立时间编码提供基于样条的时间嵌入（替代 MLP 的线性嵌入），增强各推理阶段间的独立性并为不同阶段分配渐进语义角色；残差薛定谔桥通过构建局部薛定谔桥、以可学习权重注入确定性残差先验（而非人工设定），凭借局部最优扩散路径实现灵活的确定性-随机性交互与阶段感知模糊建模。在两个公开数据集上的大量实验显示，KANResDiff 在 GED 与 HM-IoU 指标上取得最优性能，最大提升分别为 16.8% 与 7.7%，同时在 MDM 指标上保持有竞争力的表现，源码已公开。

NerveDetNet：手持多模态 OCT 无标记深层神经检测

埋在完整组织下方的周围神经在术中难以可视化，白光宽场成像与其他表面光学成像方法均无法观测。已有 OCT 神经研究多依赖暴露神经或偏振对比，穿透深度有限，限制了其在皮下术中导航中的价值。研究提出（据作者称）首个无标记框架，仅利用基于强度的 OCT 结构特征检测未切开组织下方的周围神经并解析其深度：将扫频源 OCT 与共配准的白光、自体荧光成像集成于手持多模态探头，配合为实际手术使用设计的"先确认后采集"工作流；为高效分析稀疏采样 OCT 体积，开发 NerveDetNet——轻量 2.5D 分割网络，通过专用神经特征相关模块整合空间上下文、帧序信息与跨帧位移容忍相关，恢复微弱且空间位移的神经信号。离体组织实验中，NerveDetNet 在所有帧间距上持续优于 6 种代表性 2D 基线，在最稀疏采样条件下取得 Dice 0.725，参数量约减少一半；端到端验证展示了表面不可见神经的定位与组织表面下 1.3–1.4 mm 的深度解析检测，OCT 深度图可直接叠加到手术视野。

NA-UNETR：邻域注意力 Transformer 分割左前降支动脉

背景：在三维自由呼吸、无造影剂 CT 中精确分割左前降支（LAD）动脉对胸部放疗的心脏剂量保护至关重要；LAD 极其细小、软组织对比差、个体差异大，即使人工勾画观察者间一致性也有限，凸显血管边界的模糊性。目的：开发基于 Transformer 的框架，通过局部-全局上下文建模与不确定性引导优化改善低对比、类别不平衡 CT 中的 LAD 勾画。方法：提出 NA-UNETR——三维 Transformer 分割模型，其邻域注意力（NA）与膨胀 NA（DiNA）模块联合捕获精细结构细节与长程上下文；鉴于 LAD 标注数据稀缺，模型先在 1,000 例冠状动脉 CTA 体积上预训练，再以 LoRA 参数高效微调 20 例自由呼吸机构 CT 扫描；由异方差不确定性动态平衡的组合 Dice-Focal 与 Hausdorff 损失改善重叠与边界精度。结果：NA-UNETR 达 Dice 45.64%、HD95 38.16 mm、ASD 10.01 mm，Dice 较 nnU-Net 提升 3.10 个百分点，HD95 较 Swin UNETR 降低 2.96 mm，边界精度为所有模型中最强、中心线稳定性提升；在 ImageCAS 上达 Dice 79.49%、HD95 8.89 mm、ASD 1.02 mm。消融证实残差块、可变核与不确定性加权损失各有贡献。

DD-CMD：临床文本引导肺感染分割的双域跨模态解码

临床文本可以缩小分割目标，但近期文本引导设计侧重空间对齐，忽视控制纹理与边界的频率内容。研究提出双域跨模态解码（DD-CMD）用于临床文本引导的肺部感染分割，在解码阶段集成两种互补的语言引导形式：空间域中，文本引导空间交叉注意力（TGSA）将多尺度视觉 token 与文本语义对齐，并通过门控残差融合更新特征；频率域中，频谱-文本自适应调制（STAM）应用二维 DCT 计算可学习频带能量统计，预测文本条件的 FiLM 参数以重新校准解码器通道，实现频率感知解码。DD-CMD 将 TGSA 与 STAM 嵌入从 7×7 到 56×56 的由粗到细解码器，并用轻量两阶段细化模块恢复全分辨率掩膜。在 QaTa-COV19 与 MosMedData+ 上，DD-CMD 分别取得 Dice 91.46%/mIoU 84.26% 与 Dice 81.95%/mIoU 69.42%，较最强基线平均提升 +1.96 Dice 与 +2.67 mIoU。

MaLViL：多轴低秩 Vision-LSTM 医学图像分割

Vision-LSTM（ViL）能高效建模全局信息，但计算成本随空间 token 数量增长，现有分割模型只能将 ViL 限制在粗糙的瓶颈处，从而丢失精细解剖细节；把 2D 特征光栅化为 1D 序列还会破坏正交扫描轴上的邻接关系。研究提出 MaLViL——一个多轴低秩 Vision-LSTM 分割网络，将 ViL 扩展到解码器各分辨率：双向低秩 ViL（Bi-LRViL）在紧凑标准正交子空间上推理，并通过正交残差保留细节；尺度感知的 SaLViL 在序列化前恢复跨轴邻域；跨方向混合器（CDM）融合水平与垂直两个正交遍历路径；统计引导跳跃调制（SGSM）在编码器跳跃连接中保留边界线索。在皮肤病变、超声与多器官 CT 基准上，MaLViL 取得有竞争力或最先进的分割精度，同时将 ViL 算子在精细解码器分辨率上的内存占用降低最高 83 倍，代码已公开。

Aletheia：低资源医疗环境离线优先鉴别诊断系统

撒哈拉以南非洲地区专业临床资源严重匮乏，农村地区医患比可低至 1:25,000 以下。现有 AI 辅助诊断工具大多依赖可靠网络连接与高规格硬件，在地区医院与卫生中心的基层医疗工作者手中难以实用。研究提出 Aletheia，一个面向撒哈拉以南非洲低资源医疗场景的离线优先临床决策支持系统：基于 Qwen2.5-3B-Instruct，使用 QLoRA 在涵盖东非高发 50 种疾病的 27,000 条临床推理样本数据集上微调。评估显示，在十个代表性临床病例类别上，Top-1 诊断准确率 80.0%、Top-3 准确率 100.0%、BERTScore-F1 0.909、METEOR 0.467；系统期望校准误差（ECE）0.275，通过非洲深科技挑战赛 2026（ADTC 2026）的 7,168 MB 内存预算约束，在标准化基准笔记本上峰值推理内存约 3,630 MB。结果表明，在无云基础设施的资源受限环境下，将基于大语言模型的临床推理部署到基层医疗层面是可行的。

CIPHER：因果干预路径改善医疗 AI 公平性

医学诊断深度学习模型即使平均准确率很高，也常在敏感亚组（如种族、性别）间表现出显著性能差异。生成式数据增强提供缓解途径，但现有策略通常只处理敏感属性与图像特征之间的一个或两个依赖通道。研究通过结构因果模型形式化医学图像形成过程，揭示敏感属性实际通过四条不同路径影响图像内容——这一结构复杂性被既往工作忽视；基于此提出 CIPHER（医疗公平性与稳健性的因果干预路径）框架，系统干预全部四条因果路径。CIPHER 采用配备无分类器引导与空文本反转的扩散主干，能够忠实重建患者特异解剖结构，同时支持精确、可编辑的反事实合成，以打破敏感依赖链。在胸片与皮肤镜基准的标准与偏移数据分布上测试，多路径干预策略相较疾病条件合成基线将最差组差异平均降低 35.8%，同时提升总体诊断准确率。

乳腺 X 线钙化分类的多站点无监督域适应

基于深度学习的计算机辅助诊断系统在乳腺癌诊断中表现强劲，尤其用于乳腺 X 线摄影分类任务；然而跨站点数据集的域偏移仍是挑战，尤其是模型应用于未见域时。研究提出钙化分类框架，以改善跨多站点乳腺 X 线数据集的良恶性乳腺疾病分类：框架由两部分组成——(1) 基于风格迁移模型（AdaIN 与 CycleGAN）的无监督域适应模块，无需额外标注即可生成厂商特异与技术特异的训练样本；(2) 以 Swin Transformer V2 为骨干的监督分类模块。研究在三个数据集上评估：OPTIMAM（英国 NHS，n=2,994）交叉验证，随后在 EMBED（埃默里大学，n=125）与杜克钙化数据集 v1（n=788）上外部验证；数据集覆盖多个厂商，包含全视野数字乳腺 X 线摄影与由数字乳腺断层合成导出的合成 2D 图像。框架提升了两个外部集上的跨站点性能（EMBED AUC 0.68→0.72，杜克钙化数据集 AUC 0.68→0.73），表明域适应能减少域偏移、改善跨站点钙化分类的泛化。

CardioState-JEPA：跨 ECG/PPG/PCG 共享心脏表征

心电（ECG）、光电容积（PPG）与心音（PCG）提供同一心动周期的互补视角，但现有心脏基础模型均针对单一传感模态训练，未利用跨传感器共享的生理学。研究提出 CardioState-JEPA，一个在 ECG、PPG 与 PCG 上联合学习单一共享表征的心脏基础模型，构建于生理感知的联合嵌入预测架构：模型将异质波形映射到公共 token 空间，用单一共享 Transformer 编码器处理，并通过预测掩码潜在心脏状态进行学习，将预训练目标置于共享生理而非传感器特异的波形外观上。为处理电、机械与血流动力学事件间的时间偏移，跨模态预测使用学习式延迟对齐器在相应心脏时刻对齐信号；由于同步多传感器记录稀缺，模型先从丰富的单模态数据学习模态内结构，再用配对数据在潜在心脏时间中对齐模态。作为冻结编码器在涵盖 ECG、PPG 与 PCG 的 25 个下游任务上评估，相较最佳自监督信号基线，PPG 分类平均提升 8.2 个 AUROC 点、PCG 杂音检测提升 18.8 个 AUROC 点、ECG 分类提升 15.5 个 AUROC 点，并在若干 ECG 基准上与使用特权临床文本或有监督标签训练的心脏模型相当或更优，表明异质心脏信号可以相互监督统一的心脏生理基础模型。

时间感知多视角 MRI 基准评测纵向进展推理

MRI 解读是临床决策的基础，要求放射科医生跨连续时间点整合多视角解剖平面并精确定位区间变化。然而现有视觉-语言基准局限于单时间点、单视角解读，未能捕捉放射实践中关键的时间-空间推理。研究提出时间感知多视角 MRI 基准，统一多视角解剖输入、跨纵向扫描时间推理与结构化定位引导：基准包含源自 890 名患者、覆盖 3,200 余个纵向 MRI 时间点的 3,920 对专家核验问答，来自胶质母细胞瘤、神经退行性疾病、前庭神经鞘瘤与脑转移七个临床队列，涵盖开放式、多项选择与二值格式，要求模型识别变化最大的解剖区域、跨序列与视角表征进展，并提供规定边界、影像特征与混杂因素的结构化引导。对 16 个视觉-语言模型的实验显示：中等程度的时间对齐，但在变化方向识别与体积量化上系统性失败；多视角输入改善空间定位，却在紧凑架构中削弱时间推理。该基准为临床部署所必需的进展追踪、区间变化定位与时间排序评估提供了系统框架，代码、评估划分与数据集已公开。

CytoBERT：面向流式细胞术数据的开放基础模型

细胞术测量单细胞的复杂特征（如免疫细胞数量与蛋白表达），广泛用于免疫学研究和临床场景。然而由于实验方案与所测特征的选择，细胞术数据高度异质且缺乏标准化；机器学习方法有望深入洞察细胞生物学，但这些挑战使其难以应用和跨研究迁移。基础模型的进展可缓解这些问题，但该领域相关方法仍然稀少。为此研究提供 CytoBERT——面向可变标记物面板单细胞细胞术数据的公开、开源、开放权重基础模型：在通过标记物标准化策展的大规模细胞术语料（15 个人类数据集、异质标记物面板、超 5,000 万细胞）上自监督预训练，学习细胞内可迁移的标记物间关系。将 CytoBERT 微调用于样本级分类表明，跨异质细胞术数据集的迁移学习可行，为可扩展、可泛化的细胞术分析提供起点，代码已公开。

GenFAR：49,246 例多队列 MRI 学习的脑结构通用表征

神经影像深度学习模型大多为单一任务开发，限制了跨应用的知识迁移。研究提出 GenFAR，一个模块化深度学习框架，从脑 MRI 学习通用、具有临床信息的特征：在 11 个队列、49,246 名个体上训练，覆盖认知、临床、诊断、人口学与生物标志物等 17 项分类与回归任务，产出聚合、聚焦的特征集，捕捉丰富、临床与生物学相关的脑表征。研究开发顺序学习方法，任务逐步建立在先前学习的表征之上；通过分析 5,000 条任务序列，确定最优序列长度为六项任务，并引入供体评分（Donor Score）量化每项任务对下游性能的贡献，识别出五个稳健的强供体任务（年龄、AD/MCI、MMSE、高血压、高脂血症）构成顺序模型基础。学习到的表征可在训练集之外的多种任务中作为专门次级预测器的基础，显著提高下游深度学习任务的样本效率与准确率。

EEG-PRISM：EEG 基础模型预测的生理学接地可解释性

基础模型代表 EEG 分析 AI 的下一次进步，但现有可解释 AI 技术在时间-通道输入空间提供归因分数，与临床对 EEG 的直觉不符。研究提出 EEG-PRISM，一种通用事后归因方法，可在不修改或重训练底层模型的情况下，将任意基础模型的解释扩展到替代且生理相关的域。方法利用线性变换与既定反向传播规则，将时间-通道归因分数映射到替代域：通过可逆 DFT 推导到频域的映射，通过近似可逆的 EEG 生成模型推导到源域的映射。在模拟与真实数据上，用五种基础模型与四种 AI 解释器评估跨域真实现象的恢复：模拟中 EEG-PRISM 达到近乎完美的频谱恢复与 69.2% 空间准确率；癫痫中正确判定 delta-theta 活动最显著，并以 50% 准确率正确定位癫痫发作起始区；自闭症中将预测性 delta-alpha 生物标志物定位于额叶与颞叶区域，与既往工作一致。结论：EEG-PRISM 是基于理论的事后归因方法，可准确映射到频谱与空间域，支持瞬态事件（如癫痫发作）的窗口级分析与临床相关生物标志物（如自闭症）的组级识别，推动可解释 EEG 基础模型的发展。

CoM3eT：统一病理与放射的多维多任务医学基础模型

ThyroidXAgent：可审计智能体 AI 用于甲状腺超声诊断

甲状腺超声诊断需要协调病灶定位、测量、风险分层与报告，但多数 AI 系统孤立处理这些任务，对临床审阅支持有限。研究提出 ThyroidXAgent，一个临床医生可交互的智能体 AI 系统，协调专业化诊断工具并将其输出存储为可审计的病例级证据记录。系统基于 OpenThyroidDB 开发——一个多中心、多任务资源，整合约 30 万张超声图像与 24,000 份配对报告；并在 28,458 个不重叠测试病例上评估，其中 8,721 例来自 35 个中心的私有 NHC-MISD-TUS 队列。跨异质数据集，结节分割平均 Dice 87.21%、良恶性分类平均 AUROC 0.9466；同一工作流支持淋巴结转移预测与滤泡型/乳头状甲状腺癌分类，AUROC 分别为 0.864 与 0.805。报告生成方面，证据接地组装在三个队列上优于多模态语言模型基线；研究提出的病灶级临床语义指标 ThyClinScore 与位置感知语言模型裁判的相关性最强。ThyroidXAgent 提升了医生分类准确率，将报告诊断一致性从 70.3% 提升至 86.2%，并将分割与报告时间分别缩短 35.9% 与 27.4%，支持可审计、可临床纠正的智能体 AI 用于甲状腺超声诊断与报告。

ResidencyRL：模拟临床环境强化学习训练医疗智能体

干预感知临床世界模型预测心脏术后结局

许多临床预测模型将干预后结局视为从基线测量到未来终点的一步映射，然而术后恢复常以不规则轨迹展开：临床观察、药物调整、重复干预与生理测量异步记录，随时间改变风险评估。研究提出干预感知临床世界模型：将每位患者表示为结构化潜在状态，并通过时间排序的术后干预事件演化该状态。模型先将基线影像编码为 3D 空间潜在状态，再以手术上下文、静态协变量、经过时间与围事件生理嵌入更新状态；随访影像仅通过潜在预测目标提供训练监督。研究将该框架应用于房颤消融：在 90 天恢复窗口内，不规则术后记录为长期复发风险提供临床有意义的证据；在 DECAAF-II 上重复内部交叉验证，复发预测 AUROC 0.756、AUPRC 0.777；还可在推理时不依赖随访 MRI 强度实现瘢痕范围预测（MAE 2.971 个百分点）。学习到的状态支持不同时间尺度的复发风险查询，以及对空白期记录的回顾性输入编辑。

HounsWorld：CT 潜在患者状态多模态世界模型

临床智能要求从不完备观测估计患者的潜在状况，而非学习从扫描到答案的孤立映射。体素级医学影像提供解剖、衰减与病灶的密集观测，而临床语言提供稀疏但互补的语义观测。研究将 CT 中心智能表述为对共享潜在患者状态的推断，在此框架下读取、重建与模拟都成为状态依赖的预测问题。为落实这一观点，研究提出 HounsBench——CT 中心患者状态基准，以患者不相交划分统一三类任务族并给出各家族指标；以及 HounsWorld，一个 3B 多模态世界模型，通过联合理解-生成学习将体素扫描与语言视为共享状态的观测：共享 Transformer 形成隐式患者状态估计，支持三类输出——读出的查询条件回答、以语言重建状态的报告与字幕，以及用于低剂量去噪、虚拟对比增强与解剖约束的文本-掩膜引导 CT 体积生成的条件特异 CT 体积。零初始化 CT 适配器保留预训练多模态映射，条件显式 Hounsfield 单位窗口采样暴露临床有意义的密度观测。HounsWorld 在三类任务族上均表现强劲，并通过临床结构化完成持续提升 CT 理解能力。

FEEDS：基础模型赋能 PET/CT 分割高效标注采样

全身 PET/CT 的自动化病灶分割可辅助临床医生跨示踪剂与癌种进行癌症检测、分期与治疗规划。然而训练捕捉病灶大小、分布与外观差异的分割模型需要大规模标注数据集，其创建既耗时又需专业知识；因此，在有限标注 PET/CT 数据上训练的模型常缺乏临床所需的准确性与泛化能力。研究提出 FEEDS（Foundation model-Enabled Efficient Data Sampling），一种标注与计算高效的学习策略：使用视觉基础模型嵌入从未标注病例中选择信息量最大、最具代表性的病例供专家标注。与无监督、半监督与主动学习方法不同，FEEDS 是单步训练范式，仅需有限且具有代表性的训练集。研究使用 AutoPET-III 训练并验证 FEEDS，在三个留出集（AutoPET-III、DeepPSMA 与内部达特茅斯-希区柯克医学中心数据集）上检验准确性与泛化，并在体素、病灶与解剖区域层面评估临床效用。FEEDS 优于随机采样标注、伪标签半监督学习与仅用有限标注数据训练；在三个测试集、FDG 与 PSMA 两种示踪剂及多种疾病上均可泛化，以比全标注（100%）训练少 70% 的标注负担达到相当性能，为从大型未标注临床资料库构建代表性且多样化的标注队列提供了实用方案。

LAFNO：病灶感知算子合成前列腺 PSMA-PET

从 CT 或 MRI 合成 PET 的深度学习模型可降低患者剂量与扫描仪需求，但通常以 L1 或均方误差（MSE）等全局损失优化，对所有体素一视同仁。在全身 PSMA-PET 中，肿瘤体素仅占体积的一小部分，却携带临床相关的活性信号；因此模型可能取得高结构相似性（SSIM）与峰值信噪比（PSNR），却仍低估病灶活性或无法保留肿瘤特异结构。放射组学提供肿瘤强度与纹理的生物学意义描述，但直接放射组学条件化耗时，因为需要从勾画病灶区域提取特征。研究提出 LAFNO（病灶感知自适应傅里叶神经算子）用于 CT 到 PSMA-PET 合成，以两个高效的 CT 衍生代理通道替代高维放射组学条件化：受 PSMA 亲和肿瘤核心与瘤周区域放射组学分析启发，LAFNO 使用对比度代理表征局部密度变化、紊乱度代理表征局部纹理异质性，均注入模型瓶颈；并组合全容积重建与病灶级总病灶活性（TLA）、肿瘤核心对比度与瘤周监督。在 TCIA PSMA-PET-CT-Lesions 数据集上对四种基线架构评估：LAFNO 在全容积图像质量上保持竞争力（18F- 与 68Ga-PSMA 的 SSIM 分别为 0.960 与 0.938），同时将每位患者 TLA 误差降至 48.3% 与 64.0%，并在两种示踪剂的所有特征类别上取得最高的肿瘤核心放射组学可重复性；瘤周可重复性仍依赖示踪剂，表明合成 PSMA-PET 的生物学保真度仍是挑战。

RADIANT-PET：LLM 与强化学习增强 PET/CT 病灶分割

PET/CT 中准确的病灶分割对肿瘤学至关重要，但生理性示踪剂摄取与伪影可能模拟恶性信号，使其仍具挑战。研究提出 RADIANT-PET，一个推理增强框架，将高灵敏度体素级分割模型与病灶级大语言模型（LLM）裁决相结合：先以刻意宽松的分割阶段生成候选摄取区域，再转换为结构化文本描述，概括摄取强度、形态与区域及全局解剖背景；LLM 将每个候选分类为真实病灶或假阳性，并可选利用放射学报告作为额外临床上下文。为强化病灶级推理，研究进一步用组相对策略优化（GRPO）强化学习优化本地 LLM，奖励正确的病灶分类与解剖一致的位置分配。在 AutoPET 与 OSU 测试队列上，RADIANT-PET 持续优于强图像基线，提供放射学报告时改进最大。结果表明，基于 LLM 的病灶级推理在传统分割之上增加了新颖的推理层，抑制生理性假阳性并使体素级预测与临床解读对齐。
