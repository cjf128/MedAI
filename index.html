SPECT 心肌灌注：平扫 CT 分割心肌，免手工调整

SPECT 心肌灌注显像的极坐标图定量依赖准确的心肌轮廓，但商业软件在严重心肌缺损或心外高摄取时往往需要逐例手工调整，轮廓误差会直接进入分节段血流比较。作者换了一个思路：用 125 例心肌摄取均匀的 18F-FDG PET/CT，以 PET 阈值生成心肌掩膜作为标签，训练一个只输入平扫 CT 的 nnU-Net；随后在 50 例 99mTc-sestamibi SPECT/CT 均匀摄取病例与 50 例严重缺损或心外高摄取病例上测试。DL 掩膜在 PET/CT 验证集的 Dice 为 0.866±0.035，在 SPECT/CT 测试集为 0.846±0.026；三位核医学医师的 Likert 评分显示，DL 掩膜改善了室间隔与瓣膜平面的定位，使商业软件无需手工调整即可得到可用轮廓。额外 50 例中，基底段尤其是间隔附近出现约 10% 的极坐标图分节段差异，提示自动轮廓仍会改变定量结论。

  • 研究痛点SPECT 心肌灌注的极坐标图定量依赖心肌轮廓；严重缺损、心外高摄取时商业软件需要大量手工调整，分割误差会直接传到分节段定量。
  • 方法与数据125 例均匀心肌摄取的 18F-FDG PET/CT，用 PET 阈值生成心肌掩膜，训练以平扫 CT 为输入的 nnU-Net；在 50 例 99mTc-sestamibi SPECT/CT 与 50 例严重缺损/心外高摄取病例上测试；3 位核医学医师盲评 Likert 评分。
  • 局限与迁移回顾性、测试样本有限（50+50），只覆盖单一厂商 SPECT/CT 与单中心流程；模型输入是 CT，PET 仅用于造标签；基底段约 10% 的定量差异提醒仍需人工复核。迁移到 PET/CT 时，可用 CT 先分割心肌或器官作为解剖先验，但 PET 病灶分割不能照搬“均匀摄取阈值”假设。

肺癌新辅助免疫化疗：PET/CT 影像组学预测 MPR

非小细胞肺癌接受新辅助化疗联合免疫治疗后，病理完全缓解（pCR）与主要病理缓解（MPR）是早期疗效指标，但术前只能靠 PD-L1、TMB 与常规影像间接判断。作者回顾性纳入 320 例在广东省人民医院接受至少两周期化疗免疫治疗后手术的患者，按 8:2 划分训练与内部测试（256/64），另用两家医院 31 例做外部测试。研究提取 1,834 个 CT 与 179 个 PET 影像组学特征，与人口学、肿瘤代谢参数、PD-L1、TMB 和外周血指标一起做递归特征消除，再用“模态感知注意力”融合 9 个临床、9 个 CT 与 9 个 PET 特征。训练集 AUC 0.7467（95% CI 0.6826–0.8159），外部队列 AUC 0.7017（95% CI 0.5126–0.8715），敏感度 82%、特异度 86%，高于仅用临床特征的 0.6931。

  • 研究痛点术前判断 MPR/pCR 依赖术后病理；PD-L1、TMB 与常规影像各自不足，需要把临床、PET 与 CT 信息合到一个可解释、可外部验证的模型。
  • 方法与数据351 例 NSCLC（256 训练/64 内部测试/31 外部两家医院）；1,834 个 CT + 179 个 PET 影像组学特征，加临床、代谢、PD-L1、TMB 与外周血指标；RFE 筛选 + 模态感知注意力；外部 AUC 0.7017。
  • 局限与迁移训练单中心、外部队列仅 31 例且置信区间很宽；影像组学特征依赖分割与提取参数；没有前瞻验证，也未核验到代码。迁移到鼻咽癌：可把“模态感知注意力 + 临床变量”用于 GTV/淋巴结特征融合，但终点需改为局控或生存，并重新做外部验证。

微调之前先练适配参数：PEFT 的中间自监督阶段

参数高效微调（PEFT）通常冻结预训练主干，只在监督微调阶段引入少量可训练参数，因此这些“适配参数”在拿到下游标签之前一直停留在初始状态。作者提出 Target Parameter Pre-training（TPP）：在监督微调前增加一段中间自监督阶段，主干仍然冻结，只让目标参数在下游训练图像上通过 pretext task 优化，再把学到的参数作为监督 PEFT 的初始化。TPP 不改变推理时的网络结构，可与不同主干、pretext task 和加性 PEFT 方法组合。作者在 10 个公开数据集、5 种影像模态、分类与分割两类任务上评测，TPP 提升了大多数 PEFT 方法与数据集的组合；收益依赖下游图像可得性、数据对齐程度，以及 pretext 目标与 PEFT 结构的匹配。

  • 研究痛点PEFT 的适配参数在监督微调时才引入，未利用下游图像的无标签信息；换任务或换中心时，适配参数起点随机，少量标注下的稳定性受限。
  • 方法与数据TPP 在监督微调前加一段中间自监督：主干冻结，仅用下游训练图像与 pretext task 优化目标参数，再初始化监督 PEFT；10 个公开数据集、5 种模态、分类与分割任务，与多种加性 PEFT 组合。
  • 局限与迁移方法学论文，未在 PET/CT 多中心数据上验证；收益依赖下游图像可得性、数据对齐与 pretext/PEFT 结构匹配；论文称将开源但仓库当前不可访问。迁移到 PET/CT：可先用无标注 PET/CT 预训练适配参数，再接少量标注，但需验证 SUV 归一化、重建差异与跨中心稳定性。

DAT-SPECT 报告：小模型把临床信息段结构化

多巴胺转运体 SPECT 的判读依赖症状、用药、共病与结构影像，但临床信息段常以异质自由文本记录，容易漏掉指南要素，也妨碍报告一致性。作者在汉堡-埃彭多夫大学医学中心与弗莱堡大学医学中心开发了一条本地部署的小语言模型流水线：以 Qwen3 1.7B 为基座，用 2,990 份本院报告（2,700 训练/290 内部测试）微调，两名读片医师建立 466 项、12 类的结构化字典；规则后处理负责去重、指征建议、症状侧别与时程合并、指南缺项提醒和药物相互作用检查。内部测试中，后处理输出与专家标注“信息一致”196/290（67.6%）、“完全一致”147/290（50.7%），4.5% 的差异来自自由文本歧义，14.1% 为模型错误，其中 87.8% 只涉及单个错项或漏项；外院 595 份报告中 446 份（75.0%）无需人工修正即可进入报告。

  • 研究痛点DAT-SPECT 判读依赖临床背景，但临床信息段常是异质自由文本，指南要素易漏、报告一致性差；通用大模型又不适合本地部署与隐私要求。
  • 方法与数据本地 Qwen3 1.7B 监督微调 + 466 项/12 类字典 + 规则后处理；2,990 份本院报告（2,700/290）+ 595 份外院报告；以专家标注一致率与“无修正率”评价。
  • 局限与迁移回顾性、两家德国中心，报告风格与德语语境绑定；1.7B 小模型加规则后处理，迁移到中文报告需重建字典与规则；作者含 Jung diagnostics 商业公司雇员，存在利益关联。迁移到 PET/CT 报告：可复用“小模型 + 字典 + 规则后处理 + 外部无修正率”的评估框架，但需核医学要素字典与中文脱敏流程。

医学影像智能体的预算控制器：何时停、补证据或拒答

医学影像智能体已经能在不同影像任务上给出答案，但部署时的验证预算有限，错误接受一次就可能损害临床信任。当快速检查与更深的证据复核对同一病例给出冲突结论时，系统缺少一个共享控制器来决定“停止、继续开证据、修复还是拒答”。MedHarness 把答后控制统一为“共享决策对象”：初始预测之后，由一个策略加各影像表面的配方适配器，执行最小充分验证与中间修复；新的影像表面只需注册配方即可加入同一控制器。作者在 512 例 live pool 上报告，相比全验证基线，错误接受约减少 47%，在 86.1% 覆盖率下接受准确率 83.2%（基线 72.9%）；在失败富集的多表面压力排序中，每例远程服务调用约减少 71%；三表面留出集与更换语言模型的迁移实验保持同一控制排序。

  • 研究痛点影像智能体在不同扫描面与任务上答题，验证预算有限；薄检查与深证据冲突时缺少统一的停止/补证/修复/拒答控制，错误接受会损害临床信任。
  • 方法与数据MedHarness：共享决策对象 + 最小充分验证 + 中间修复，一个策略加表面配方适配器；512 例 live pool；与全验证基线比较错误接受、覆盖率与调用成本；三表面留出与换模型迁移。
  • 局限与迁移预印本；live pool 的病例构成与任务分布需读全文；未做临床前瞻或真实工作站部署；代码为匿名仓库，未核验到作者实名官方仓库。迁移到 PET/CT 科研流水线：可把 DICOM 转换、配准、分割、SUV 定量注册为“表面”，由统一控制器决定补证或拒答，但需先定义每个工具的失败判据与证据成本。

有好掩膜还不够：智能体还要学会管理证据呈现

医学视觉语言智能体越来越依赖分割工具，但现有研究多把“拿到正确掩膜”当作工具使用的终点，忽略了智能体如何使用这份证据。作者构建 Mask-Evidence MedVQA：2.5K 例、4 类医学影像，每个问题配一张与答案相关的金标准掩膜，并允许同一掩膜以多种方式渲染。结果显示两个问题：证据呈现方式会显著改变模型行为；掩膜既可能暴露此前漏掉的诊断证据，也可能诱导错误关联，连金标准掩膜都会把一些原本正确的答案改错。为此提出 TUNE 证据管理框架，显式决定“取什么证据、怎么呈现、是否采纳答案更新”。在 7 个公开医学 VQA 基准上，TUNE 比直接工具使用平均高 9.1 分，微调的 Qwen3.5-9B 主干平均提升 4.0 分。

  • 研究痛点智能体把“拿到好掩膜”当终点，但同一掩膜的不同呈现会改变模型判断；高亮证据既可能纠正错误，也可能诱导错误关联。
  • 方法与数据Mask-Evidence MedVQA：2.5K 例、4 类影像，每题配答案相关金标准掩膜与多种渲染；TUNE 显式管理证据获取、呈现与答案更新；7 个基准，平均比直接工具使用高 9.1 分。
  • 局限与迁移预印本；以 VQA 准确率为终点，未覆盖报告生成或临床工作流；4 类影像以二维为主，未验证三维 PET/CT；证据呈现方式仍有限。迁移到 PET/CT：可把 SUV 阈值、掩膜叠加、箭头或文本化描述作为呈现变量，测试其对病灶判断与报告结论的影响。

把 tau 扩散方程写进图网络：纵向 PET 进展预测

tau 病理沿脑网络扩散，纵向 tau PET 能定量区域负荷，DTI 能给出结构连接组，因此图神经网络很适合做进展预测；但纯数据驱动 GNN 容易过拟合，也未必学到真实的传播机制。作者把 Fisher-Kolmogorov-Petrovsky-Piskunov（FKPP）反应-扩散方程与 epidemic spreading model（ESM）作为正则项，加在 GNN 的潜空间里，构建物理信息图网络，用 ADNI 中 462 名淀粉样蛋白阳性受试者的 tau PET 与 DTI 数据做训练与留出评估。结果显示，物理信息模型在多项指标上优于无正则基线，FKPP 的平均预测性能最好，ESM 紧随其后；潜空间正则比特征空间正则更稳健；Integrated Gradients 归因集中在生物学相关区域，与性能提升一致。

  • 研究痛点tau 沿脑网络扩散，纯数据驱动 GNN 易过拟合，难以保证学到的是传播机制而不是站点或批次效应。
  • 方法与数据FKPP 与 ESM 物理先验作为潜空间正则，构建物理信息 GNN；ADNI 462 名淀粉样蛋白阳性受试者的 tau PET + DTI；多指标比较、潜空间/特征空间正则消融、Integrated Gradients 归因。
  • 局限与迁移单队列（ADNI）、无外部队列；状态是 ROI 级 tau 负荷，不含治疗与临床变量；未做干预反事实。迁移到鼻咽癌 PET/CT：可把“代谢体积/淋巴结负荷 + 解剖连接”作为状态，用物理先验约束纵向进展，但需纵向 NPC 队列、治疗变量与外部验证。

临床世界模型：支持度不足时先拒答

临床世界模型会把“模拟的患者反应”喂给语言模型智能体，但在支持不足的治疗或陌生医院，模拟可能不可靠，智能体却容易照单全收。作者提出 Support-Gated World-Model：用循环动力学集成预测去甲肾上腺素剂量类别下的短期生理反应，另用行为模型估计该动作在观察数据中的支持度；当支持不足或集成分歧过大时，系统不输出预测，没有合格候选时直接弃权。评估使用 eICU-CRD 的 70 家医院、30,700 条决策转换，其中 14 家医院留出测试。在 62.0% 的事实转换覆盖率下，联合门控的 MAP 平均绝对误差为 7.3 mmHg（同覆盖率随机选择 9.2 mmHg）；门控智能体在 81.0% 决策覆盖率下与记录动作一致率 60.0%，无门控集成在 99.5% 覆盖率下为 55.0%。

  • 研究痛点临床世界模型在支持不足或跨院时会给出不可靠的模拟，语言模型智能体却缺少“该不该信”的门控，容易把低支持度预测当成事实。
  • 方法与数据循环动力学集成预测短期生理反应 + 行为模型估计动作支持度 + 联合门控/弃权；eICU-CRD 70 家医院、30,700 条决策转换、14 家留出；报告覆盖率-误差-一致率权衡。
  • 局限与迁移预印本；观察性数据，不能识别个体化疗效或改善结局；只覆盖去甲肾上腺素与单一数据源；非影像研究。迁移到 PET/CT：可把“支持度”定义为治疗或扫描协议在训练队列中的覆盖，纵向 PET/CT 状态预测也应报告覆盖率-可靠性曲线，而不是只报平均误差。

报告结构化模型别只报准确率：先定义可接受修正率

把自由文本临床信息结构化的模型，最终要嵌进报告系统；评价时应看“医生还要改多少”，而不是词级相似度。本期 DAT-SPECT 研究（2,990 份内部 + 595 份外部报告）同时报告：与专家标注完全一致 50.7%、信息一致 67.6%、外院无需修正 75.0%，并把 4.5% 的差异归因于自由文本歧义、14.1% 归因于模型错误。为什么重要：BLEU/ROUGE 或内部准确率高，不代表指南要素齐全、字段可直接进报告；修正率才是临床采纳的成本。

  • 操作要点① 先定义“严格修正”标准，把错项、漏项与自由文本歧义分开；② 同时报告内部与外部无修正率、单错误项占比；③ 把规则后处理与模型分开消融，确认收益来源；④ 错误按字段与类别分层；⑤ 用真实报告做端到端计时，而不只看离线指标。
  • 适用条件适用于报告结构化或信息抽取任务，有专家标注与至少一个外部机构，并需要可审计的字段字典；不适用于无金标准、以开放性写作为目标的任务。
  • 常见误区① 用 token 相似度代替临床可接受性；② 只报内部测试，忽略外院报告风格差异；③ 把自由文本歧义算成模型错误，低估上限；④ 忽略规则后处理的贡献，把系统收益全归给模型。
