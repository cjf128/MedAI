推理时正交种子提升三维器官分割对齐

三维医学图像分割中，稠密体素级标注是主要瓶颈。Sli2Vol 等单切片传播方法通过无标签配准把一张标注种子切片传播到整个体积，减轻标注负担；但仅沿轴向传播会随距种子距离增加而累积误差，尤其在表面距离指标上，因为它忽略冠状面与矢状面证据、未充分利用 CT/MRI 体积中的三维信息。研究系统考察影响切片传播模型的关键训练与推理选择（单轴与多轴无标签配准、单种子与多种子传播、正交种子配置），提出用三个正交种子（轴向、冠状、矢状各一）替代单一轴向种子，并以简单无标签规则融合其传播标签。结果显示训练范式影响有限：轴向训练网络用于离轴种子即可获得几乎全部提升，显式三轴训练增益甚微；性能主要由推理时种子几何驱动，正交性比标注切片数量更重要，预算匹配的三轴对照无增益甚至可能下降。在多器官 CT 队列上，正交种子配合轴向 Sli2Vol 主干相较单轴基线将 Dice 提升 21.9%、归一化表面 Dice 提升 25.5%、平均 Hausdorff 距离降低 53.5%。

M-Net：融合谱特征与物理场算子的医学分割

深度学习医学图像分割已取得显著成功，但纯数据驱动方法往往未能利用医学图像中固有的数学结构。研究考察显式数学归纳偏置——矩阵谱分析与矢量微积分算子——能否在数据驱动学习之外进一步增益分割。提出 M-Net（数学增强网络），在 U-Net 中集成三类互补数学先验：(1) 由中心化局部像素矩阵条件数导出的连续谱特征，提供纹理病态性的可微度量；(2) 由图像梯度场计算的物理场算子（散度与离散类旋度边界不规则算子），捕捉焦点强度极值与边缘非光滑性；(3) 数学注意力门（MAG），在跳跃连接处自适应融合数学特征与 CNN 提取的深度特征。在 LiTS、KiTS 与 BraTS 三个基准上，M-Net 的 Dice 分别达 78.42%、76.15% 与 83.67%，较基线 U-Net 在肝脏、肾脏与脑肿瘤分割上提升 12.37%、3.52% 与 5.55%。消融显示条件数特征较二值可逆性特征增益 2.14%，MAG 较简单拼接增益 1.45%，确立数学归纳偏置能为医学图像分割提供有效互补信息。

03

FS-JEPA：KAN 函数空间预测学习分割

Kolmogorov–Arnold 网络（KAN）将每条网络边参数化为可学习的单变量函数，引入显式函数表示；但现有基于 KAN 的分割模型只在边聚合后的目标上优化边函数，各边函数缺乏聚合前的显式学习目标。研究提出面向医学图像分割的函数空间联合嵌入预测学习（FS-JEPA），把预测学习移入 KAN 聚合前的函数空间：掩码在线分支预测由全上下文指数移动平均目标分支生成的采样 KAN 边函数的结构化签名，共享边索引保持预测与目标的对应关系；为避免预测孤立边响应，用围绕输入锚点的函数求值组成多半径签名来表示每条采样边函数，捕获单响应无法刻画的结构化局部函数变化。函数空间目标与分割损失在训练中联合优化，推理时移除预测分支。在五个医学图像分割基准上，FS-JEPA 取得最佳平均 Dice，较最强 KAN 竞争方法提升 2.25 个百分点。

跨站点钼靶钙化分类的无监督域适应

基于深度学习的钼靶计算机辅助诊断在乳腺癌分类上表现良好，但多站点数据集间的域偏移仍是挑战，尤其当模型应用到未见域时。研究提出跨站点钼靶数据集的良恶性钙化分类框架，包含两部分：(1) 基于风格迁移模型（AdaIN 与 CycleGAN）的无监督域适应模块，无需额外标注即可生成厂商特异与技术特异的训练样本；(2) 以 Swin Transformer V2 为骨干的监督分类模块。在三个数据集上评估：OPTIMAM（英国国家医疗服务体系，n=2994）交叉验证，随后在 EMBED（埃默里大学，n=125）与杜克钙化数据集 v1（n=788）外部验证，覆盖多种厂商与全视野数字钼靶、数字乳腺断层合成导出的合成 2D 图像。该框架将 EMBED 与杜克数据集的跨站点性能分别从 AUC 0.68 提升至 0.72、0.68 提升至 0.73，表明域适应能减小域偏移、改善跨站点钙化分类的泛化。

平衡软专家混合模型提升青光眼检测

青光眼是一组损伤视神经的眼病，常由眼压升高引起，是不可逆视力丧失的主要原因之一，起病缓慢且早期几乎无症状，早期检测对预防或延缓视力损失至关重要。基于深度学习的单模态模型已提升青光眼检测的准确率与效率；在此基础上，多模态模型利用不同成像模态的优势学习更丰富稳健的表征，进一步提升了检测准确率。然而多模态学习因联合学习目标面临单模态表征不平衡、欠优化等问题。研究提出带负载均衡损失的平衡软专家混合模型（含三个专家），在 AUC 指标上超越所有单模态基线、常规多模态模型及当前最优的平衡多模态模型，且可泛化至糖尿病视网膜病变等其他疾病检测。

视网膜基础模型潜空间的临床可控生成评估

医学基础模型学习临床相关表型的潜在表征，但其支持可控图像生成的能力仍鲜有探索。研究在表示分词器框架内评估四个视网膜基础模型，考察潜表征中编码的人口学与临床信息在合成图像生成时是否得以保留。结果显示，在其来源基础模型内评估时，生成的表征与图像能忠实继承表型信息，在多个下游预测任务上一致优于传统潜扩散；但当用真实图像训练的独立分类器评估时，这些增益大多消失，揭示出此前未被表征的合成到真实表示差距。研究证明基础模型潜空间为可控视网膜合成提供了强基底，同时强调需要更好对齐合成表征与真实图像分布。

纵向 MRI 疾病进展推理：多视图时间基准

MRI 解读是临床决策的基础，放射科医生需要跨连续时间点整合多视图解剖平面并精确定位间隔变化；现有视觉语言基准局限于单时间点、单视图解读，无法覆盖放射实践中不可或缺的时间-空间推理。研究提出时间感知多视图 MRI 基准，统一多视图解剖输入、跨纵向扫描的时间推理与结构化定位引导：由 7 个临床队列（胶质母细胞瘤、神经退行性疾病、前庭神经鞘瘤与脑转移）890 名患者、3,200+ 纵向 MRI 时间点生成 3,920 个专家验证问答对，涵盖开放式、多项选择与二分类形式，要求模型识别最大变化解剖区域、跨序列与视图表征进展、提供指定边界、影像特征与混杂因素的结构化引导。16 个视觉语言模型实验显示时间对齐中等，但在变化方向识别与体积量化上系统性失败；多视图输入改善空间定位，却在紧凑架构中削弱时间推理。该基准为进展追踪、间隔变化定位与时间排序等临床部署必需能力的评估提供了系统框架。

CardioState-JEPA：跨模态共享心脏表征

心电图（ECG）、光电容积脉搏波（PPG）与心音图（PCG）提供同一心动周期的互补视角，但现有心脏基础模型均针对单一传感模态训练，未利用传感器间的共享生理学。研究提出 CardioState-JEPA——基于生理感知联合嵌入预测架构的心脏基础模型，跨 ECG、PPG、PCG 联合学习单一共享表征：将异构波形映射到公共 token 空间，用单一共享 Transformer 编码器处理，通过预测掩码潜在心脏状态进行学习，把预训练目标放在共享生理学而非传感器特定波形外观。针对电学、机械与血流动力学事件间的时间偏移，跨模态预测使用学习到的延迟对齐器在对应心脏时间匹配信号。鉴于同步多传感器记录稀缺，模型先从丰富的单模态数据学习模态内结构，再用配对数据在潜在心脏时间对齐模态。作为冻结编码器在覆盖 ECG、PPG、PCG 的 25 个下游任务上评估：较最佳自监督信号基线，PPG 分类平均提升 8.2 AUROC 点、PCG 杂音检测提升 18.8 AUROC 点、ECG 分类提升 15.5 AUROC 点，并在多个 ECG 基准上匹配或超越以特权临床文本或监督标签训练的模型。

ThyroidXAgent：可审计的甲状腺超声智能体

甲状腺超声诊断需要协调病灶定位、测量、风险分层与报告生成，但多数 AI 系统孤立处理这些任务，对临床审查的支持有限。研究提出 ThyroidXAgent——临床医生可交互的智能体 AI 系统，协调专门诊断工具并将其输出存储为可审计的病例级证据记录。系统基于 OpenThyroidDB 开发（多中心、多任务资源，整合约 30 万张超声图像与 2.4 万份配对报告），在 28,458 例不重叠测试病例上评估，含私有 NHC-MISD-TUS 队列 35 个中心的 8,721 例。在异构数据集上，结节分割平均 Dice 87.21%、良恶性分类平均 AUROC 0.9466；同一流程支持淋巴结转移预测与滤泡型/乳头状甲状腺癌分类，AUROC 分别为 0.864 与 0.805。报告生成方面，证据锚定组装在三个队列上优于多模态语言模型基线；新引入的 ThyClinScore 病灶级临床语义指标与位置感知语言模型评判相关性最强。ThyroidXAgent 提升医生分类准确率、将报告诊断一致性从 70.3% 提升至 86.2%，分割与报告时间分别减少 35.9% 与 27.4%。

MARC：开源多智能体临床推理框架

研究提出多智能体推理与协调（MARC）开源框架，以确定性多智能体编排替代整体式 LLM 提示，用于临床推理：协调角色专化的智能体分别承担提取、推理、答案生成与评估，显式传递上下文并提供可追溯的中间输出，支持分阶段失败归因。另引入 Decomposer 模块，从自然语言任务描述自动生成任务特定智能体提示，省去手工提示工程。框架支持 API 与本地 CPU 兼容部署，完全通过 YAML 配置、无需修改代码，设计为模型无关、可解释，临床领域专家无需编程经验即可使用；完整框架已在 GitHub（Penn-RAIL/MARC-v1）以 MIT 许可开源。

干预感知临床世界模型预测心脏术后结局

许多临床预测模型把术后结局视为从基线测量到未来终点的一步映射；但术后恢复常呈现不规则轨迹：临床观察、用药调整、重复干预与生理测量异步记录，并随时间改变风险评估。研究提出干预感知临床世界模型：用结构化潜在状态表示每位患者，并通过按时间排序的术后干预事件演化该状态。模型先将基线影像编码为三维空间潜在状态，再用手术背景、静态协变量、经过时间与围事件生理嵌入更新状态；随访影像仅提供训练监督（潜在预测目标）。应用于房颤消融：90 天恢复窗口内的不规则术后记录为长期复发风险提供有临床意义的证据。在 DECAAF-II 上重复内部交叉验证，复发预测 AUROC 0.756、AUPRC 0.777；无需随访 MRI 强度，疤痕范围 MAE 2.971 个百分点。学习到的状态支持不同时间水平的复发风险查询与空白期记录的回顾性输入编辑。

HounsWorld：CT 患者状态多模态世界模型

临床智能需要从不完整观测估计患者潜在状态，而非学习从影像到答案的孤立映射。体积医学图像提供解剖、衰减与病灶的稠密观测，临床语言则提供稀疏但互补的语义观测。研究将以 CT 为中心的智能形式化为对共享潜在患者状态的推理——读出、重建与模拟都成为状态依赖的预测问题。据此提出 HounsBench（以 CT 为中心的患者状态基准，统一三类任务族，患者不重叠划分、逐族指标）与 HounsWorld（3B 多模态世界模型）：通过联合理解-生成学习，把体积扫描与语言视为共享状态的观测，由共享 Transformer 形成隐式患者状态估计，支持三类输出——读出状态的查询条件回答、以语言重建状态的报告与描述、条件特定 CT 体积生成（低剂量去噪、虚拟对比增强与解剖约束的文+掩码到体积生成）。零初始化 CT 适配器保留预训练多模态映射，条件显式 HU 窗采样暴露临床有意义的密度观测。HounsWorld 在三类任务族均表现强劲，并通过临床结构化补全持续提升 CT 理解。

PET/CT 放射基因组多标签预测肺癌突变

肺癌是全球癌症相关死亡的主要原因之一。靶向治疗改善了非小细胞肺癌（NSCLC）患者的预后，但依赖通过组织活检进行的突变检测，而活检属于有创操作且存在局限。研究考察基于 PET/CT 的放射基因组学预测 EGFR、TP53 与 KRAS 突变，并评估成对多标签学习相比传统单基因分类能否提升突变预测性能；据作者所述，这是首批系统研究 PET/CT 放射基因组学突变预测中多标签学习的 NSCLC 工作之一。实验在一个新型英国放射基因组学队列上进行：KRAS 与 TP53 联合预测将 KRAS AUC 从 0.58 提升至 0.64、TP53 从 0.69 提升至 0.71；EGFR/KRAS 组合仅 EGFR 获益，EGFR/TP53 组合无改善。结果表明多标签学习的有效性取决于所建模的基因突变组合，提示 PET/CT 放射基因组预测或需突变特异建模策略。

LAFNO：病灶感知算子合成 PSMA-PET

从 CT 或 MRI 合成 PET 的深度学习模型可降低患者辐射剂量与扫描需求，但通常用 L1 或均方误差等全局损失优化，对所有体素一视同仁。在全身 PSMA-PET 中，肿瘤体素仅占很小体积，却携带临床相关的活性信号；因此模型可能在 SSIM 与 PSNR 很高的情况下仍低估病灶活性或丢失肿瘤特异结构。放射组学提供肿瘤强度与纹理的生物学意义描述，但直接以放射组学条件化需要从勾画病灶提取特征，耗时费力。研究提出 LAFNO——病灶感知自适应傅里叶神经算子，用于 CT 到 PSMA-PET 合成：以两个高效的 CT 衍生代理通道替代高维放射组学条件化——对比代理表征局部密度变化、无序代理表征局部纹理异质性，均注入模型瓶颈；结合整体体积重建与病灶级总病灶活性（TLA）、肿瘤核心对比与瘤周监督。在 TCIA PSMA-PET-CT-Lesions 数据集上对比四个基线架构：整体图像质量保持竞争力（18F- 与 68Ga-PSMA 的 SSIM 分别为 0.960 与 0.938），患者级 TLA 误差分别降至 48.3% 与 64.0%，并在双示踪剂所有特征类别中取得最高肿瘤核心放射组学可重复性；瘤周可重复性仍呈示踪剂依赖，提示合成 PSMA-PET 的生物学保真仍具挑战。

GLOW-FDG：泛癌全身 FDG-PET/CT 病灶分割

全身氟脱氧葡萄糖正电子发射断层扫描联合计算机断层扫描广泛用于肿瘤诊疗，但人工病灶勾画缓慢、主观且难以规模化。研究提出开源 AI 模型 GLOW-FDG，用于 FDG-PET/CT 全身肿瘤病灶分割：在覆盖多种癌症类型的 1,563 次扫描上训练，并在独立机构的 185 次外部扫描上评估。在乳腺癌、非转移性与寡转移性肺癌、头颈癌与转移性黑色素瘤中，GLOW-FDG 在病灶检测上一致优于公开基准模型，同时减少假阳性并保持强分割精度；总肿瘤负荷与总病灶糖酵解定量在各队列稳健，性能接近专家放射肿瘤科医生之间的变异。结果支持 GLOW-FDG 作为全身成像中自动化肿瘤分割与定量影像生物标志物提取的泛化工具。
