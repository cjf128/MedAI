协议流形覆盖学习：免源主动适配提升多中心鼻咽癌原发灶分割

鼻咽癌原发灶（GTVp）在增强 T1 MRI 上的分割模型跨中心部署时，常因扫描协议混杂出现系统性域偏移：Dice 看似稳定，但 95% 豪斯多夫距离（HD95）显著增大，说明边界整体外漂，而边界精度直接决定靶区范围与处方剂量。福州大学与福建省肿瘤医院团队提出协议流形覆盖学习（PMCL），一种免源（source-free）主动域适配框架：在极小切片标注预算下，不依赖源域数据或伪标签即可挑选目标域查询样本；用紧凑的协议签名量化协议差异，通过协议感知扰动分离出边界带上的协议分歧，并以组先验覆盖约束防止采样坍缩。在 6 家中心、1289 例容积数据、10% 标注预算下，PMCL 优于所比较的现有方法，平均 Dice 提升约 0.10、平均 HD95 减少约 3.9 mm。

  • 研究痛点鼻咽癌 GTVp 分割模型跨中心部署时受采集协议混杂影响，出现边界漂移：Dice 尚可而 HD95 明显恶化，指标掩盖了几何错误；常规域适配依赖源域数据或伪标签，在多中心数据不可出院的场景下不可行。
  • 方法与数据免源主动域适配框架 PMCL。6 家中心共 1289 例增强 T1 MRI 容积，10% 标注预算；以紧凑协议签名量化协议差异，用协议感知扰动隔离边界带协议分歧（Protocol Disagreement），并以组先验覆盖约束避免采样坍缩；所选目标域样本同时用于适配与再标注。平均 Dice 提升约 0.10，平均 HD95 下降约 3.9 mm，优于所比较的现有方法。
  • 局限与迁移会议论文，原文模态为增强 T1 MRI，不含 PET 或代谢通道；评估集中在鼻咽癌单病种与 GTVp 单靶区，未覆盖淋巴结靶区（GTVn）与复发、转移灶；主动标注仍需人工介入，10% 预算的绝对成本取决于队列规模；未见跨厂商、跨重建算法的分层结果。对本项目，可迁移的是“以协议签名量化域偏移、把边界带作为适配重点”的做法：PET/CT 多中心数据同样存在重建与采集协议差异，可把 SUV 归一化口径与重建核函数纳入协议签名，并把 HD95 与表面距离列为与 Dice 并列的主指标。

LION：FDG 与 PSMA PET/CT 全自动病灶分割的数据中心化流程

全身 PET/CT 病灶分割长期依赖多模态输入与大量标注，且不同示踪剂、不同病种之间性能差异很大。维也纳医科大学 QIMP 团队与库内奥、佛罗伦萨、埃森等中心合作，提出并验证 LION——一个仅用 PET 的肿瘤分割流程，覆盖 [18F]FDG 与 PSMA 靶向两类示踪剂。研究用 5209 例 FDG PET/CT（涵盖 19 类疾病）与 2046 例 PSMA PET/CT 训练，把生理性摄取器官作为辅助类别以支持仅 PET 推理；并提出肿瘤出现图（TOM）量化训练数据中的肿瘤空间多样性。结果显示，加入器官上下文把中位 Dice 由 0.62 提升至 0.71（FDG）、由 0.75 提升至 0.83（PSMA）；TOM 衡量的空间多样性与 Dice 强相关（Spearman ρ 为 0.80，P 为 0.003）；用 500 例训练的混合疾病模型即可达到 3031 例训练的淋巴瘤专科模型水平；最终在 616 例 FDG 与 443 例 PSMA 多中心留出队列上取得中位 Dice 0.71 与 0.85，优于所比较的其它开源工具；并以 DINOv2 嵌入揭示了同病种不同扫描仪之间的域偏移。

  • 研究痛点全身 PET/CT 病灶分割通常需要 CT 或多序列输入与大量标注；示踪剂与病种变化会显著影响泛化，而训练数据的病种构成对性能的影响缺少可量化指标；多中心之间还存在扫描仪与重建带来的域偏移。
  • 方法与数据多中心回顾性研究。5209 例 FDG PET/CT（19 类疾病）与 2046 例 PSMA 靶向 PET/CT 训练仅 PET 分割模型；生理摄取器官设为辅助类别以支持无 CT 推理；以肿瘤出现图（TOM）量化肿瘤空间多样性；用 DINOv2 嵌入分析扫描仪域偏移。多中心留出队列为 616 例 FDG（4 类疾病）与 443 例 PSMA 前列腺癌，并与 3 个开源工具比较。器官上下文使中位 Dice 由 0.62 升至 0.71（FDG）、由 0.75 升至 0.83（PSMA）；最终中位 Dice 为 0.71（FDG）与 0.85（PSMA）；TOM 与 Dice 的 Spearman ρ 为 0.80。
  • 局限与迁移回顾性研究，留出队列来自参与中心，未做前瞻性验证；仅 PET 推理以舍弃 CT 解剖信息为代价，小病灶与紧邻生理摄取处的误差需逐部位评估；模型对比集排除了 autoPET 测试病例，与公开基准的可比性受限；扫描仪多样性虽有分析但未给出分层结果。对本项目，可迁移的是“用空间多样性指标指导训练集配比”与“把生理摄取器官设为辅助类别”两项做法，可直接用于 PET/CT 肿瘤分割的数据构建与假阳性抑制；迁移到头颈部靶区时需重新定义生理摄取器官集合。

ProMoE：以专家原型驱动示踪剂自适应路由的多示踪剂 PET 分割

PET/CT 正从单示踪剂走向多示踪剂，但区分病理性病灶与生理性摄取依然困难，且这一判断强烈依赖解剖位置与示踪剂种类。常规混合专家（MoE）架构理论上支持多任务学习，却依赖特征驱动的门控，路由不可控，难以利用放射学判读所需的解剖与示踪剂先验。上海科技大学与联影智能等团队提出 ProMoE：引入一组可学习的专家原型，作为语义嵌入空间中的锚点来表征特定生理情境；推理时先把输入按解剖与示踪剂先验映射到该空间，再依据嵌入与专家原型的相似度激活专家，从而实现生理引导的专家专化与示踪剂自适应路由。在 1366 例、覆盖 18F-FDG、18F/68Ga-PSMA 与 18F-FAPI 三种示踪剂的多中心数据集上，ProMoE 的平均 DSC 比最优对比方法高 5.97%；在 30 例未见示踪剂（CD70）的先验引导零样本迁移中进一步提升 8.82% DSC。

  • 研究痛点多示踪剂 PET/CT 中病灶与生理摄取的区分依赖解剖位置与示踪剂种类；常规 MoE 的门控由特征驱动，路由不可控，无法显式利用放射学先验，导致跨示踪剂泛化差、专家专化不可解释。
  • 方法与数据ProMoE 为原型驱动混合专家框架：一组可学习专家原型在语义嵌入空间中表征特定生理情境，推理时按解剖与示踪剂先验嵌入输入，再按嵌入与原型相似度完成示踪剂自适应路由。数据为 1366 例多中心 PET/CT，覆盖 18F-FDG、18F/68Ga-PSMA 与 18F-FAPI 三种示踪剂。平均 DSC 较最优对比方法提升 5.97%；在 30 例未见示踪剂 CD70 的先验引导零样本迁移上 DSC 提升 8.82%。
  • 局限与迁移会议论文，未见独立外部队列的前瞻验证；未见示踪剂的零样本评估仅 30 例且为单一示踪剂，样本量小、未报告置信区间；作者团队包含商业公司（上海联影智能），数据与评测流程存在利益相关性，需注意解读；未报告分割不确定性与失败样本的解剖分布。对本项目，可迁移的是“用解剖与示踪剂先验约束专家路由”的思路，可用于 FDG 与 PSMA 等多示踪剂 PET/CT 的联合建模；迁移到鼻咽癌场景前需先明确可用的示踪剂组合与解剖先验来源。

RADIANT-PET：用大语言模型病灶级裁决压制 PET/CT 分割的生理性假阳性

PET/CT 病灶分割的核心难点并非勾出高摄取区域，而是判断哪些高摄取是恶性病灶、哪些是生理性摄取或伪影。俄亥俄州立大学综合癌症中心与玛希隆大学、Mettapracharak 医院团队提出 RADIANT-PET：先用一个刻意宽松的体素级分割模型生成候选高摄取区域，再把每个候选转换为结构化文本描述（摄取强度、形态、局部与全局解剖上下文），交由大语言模型判定为真病灶或假阳性，并可选地接入影像报告作为临床上下文；进而用组相对策略优化（GRPO）强化学习微调本地模型，奖励正确的病灶分类与解剖一致的部位归属。在 autoPET 与本院测试队列上，该框架稳定优于纯图像的强基线，提供影像报告时提升最明显。作者强调这是为分割增加一层病灶级推理，而非替代体素级模型。

  • 研究痛点PET/CT 中生理性摄取、炎症与伪影常与恶性病灶信号重叠，纯体素级分割模型倾向高召回低精度，假阳性会直接污染 MTV、TLG 等定量指标并影响分期判断。
  • 方法与数据两阶段框架。体素级分割先产生宽松候选；候选被转为含摄取强度、形态与解剖上下文的结构化文本；大语言模型逐候选二分类为真病灶或假阳性，可选接入影像报告；用 GRPO 强化学习微调本地模型，奖励正确分类与解剖一致的部位归属。在 autoPET 与俄亥俄州立大学测试队列上与纯图像基线比较，报告一致优于强图像基线，提供报告时提升最大；并指出通用医学视觉语言模型 MedGemma 在病灶级分类上表现较弱。
  • 局限与迁移会议论文，未报告病灶级指标的完整置信区间与统计检验；依赖影像报告文本，报告可得性与质量会影响结果；以大语言模型做裁决带来的提示敏感性、模型版本漂移与可解释性问题尚未系统评估；未报告失败样本的解剖分布。对本项目，可迁移的是“放宽分割阈值、再用病灶级判定收窄”的两阶段设计，可用于 PET/CT 淋巴结与转移灶的假阳性抑制；迁移时应固定模型版本并报告其裁决一致性。

Med-RADIO：多教师蒸馏把各模态专家压缩进统一医学影像基础模型

医学影像基础模型面临两难：专科模型在各自模态上性能最好，通用模型却因训练数据规模不足、域内深度不够而普遍低于专科上限。中国科学院香港创新研究院团队提出 Med-RADIO，目标是“把全部领域压缩进一个模型”：同时挑选通用教师与专科教师，为不同模态分配对齐的蒸馏流，重排通用预训练数据使其与专科领域匹配，并用平衡损失防止单一教师主导蒸馏过程，从而把互补的专科能力压进统一的医学视觉基础模型。在覆盖五种模态的内部与外部分类基准上，Med-RADIO 在线性探测下优于强医学通用模型，在多数模态上与代表性专科模型相当。

  • 研究痛点医学通用基础模型的数据规模远小于自然图像通用模型，域内深度又不及专科模型，形成“通用低于专科上限”的基线缺口；简单混合多模态数据预训练无法吸收专科模型中已固化的领域知识。
  • 方法与数据多教师蒸馏框架 Med-RADIO：同时选取通用与专科教师；按模态分配对齐的蒸馏流，将通用预训练数据重组以匹配专科领域；用平衡损失避免任一教师主导。评测覆盖五种模态的内部与外部分类基准，采用线性探测，并与强医学通用模型及代表性专科模型比较。
  • 局限与迁移预印本 v1，尚未经同行评审；评测以分类（线性探测）为主，未覆盖分割、检测或三维多模态任务；教师的选择与配比缺少敏感性分析；结论建立在二维及多模态分类基准上，向 PET/CT 这类体积多模态数据的迁移尚未验证。对本项目，可迁移的是“以专科教师校准通用模型”的训练范式：可用 PET/CT 单任务专家模型作为教师，蒸馏进通用三维编码器，再检验其在头颈部或全身分割上的迁移效果。

制品化 Agent 框架：让医学影像处理既自适应又可复现

医学影像研究正从受控基准评测走向真实临床部署，此时“跑通一个方法”不再只是模型设计问题，而需要按数据集条件配置流程并保留可追查的来源记录。范德比尔特大学团队提出一个制品化（artifact-based）Agent 框架：用“制品契约”形式化中间与最终输出，使流程状态可被结构化查询，并可按目标从模块化规则库中组装配置；执行交给工作流执行器，以保证确定性计算图构建与溯源，Agent 本身在本地运行以符合多数隐私约束。作者在真实临床 CT 与 MRI 队列上评估，展示了自适应配置合成、重复执行下的确定性复现与基于制品的语义查询：状态与溯源类查询全部正确，数据集类查询仅出现一到两次错误，错误主要来自不完整或损坏的 DICOM 头信息。

  • 研究痛点影像分析方法的真实部署需要按数据集条件配置流程并保留可追查记录，但既有流程既难以适应异构队列，也常缺少确定性复现与溯源机制；把大模型直接接入流程又会带来隐私与不可复现的风险。
  • 方法与数据制品化 Agent 框架：以制品契约形式化中间与最终输出，支持流程状态的结构化查询与目标条件化的配置组装；执行委托给工作流执行器以保持确定性计算图与溯源；Agent 在本地运行以适配隐私约束。在真实临床 CT 与 MRI 队列上评估确定性复现、跨队列配置合成与语义查询（状态、过滤计数、溯源三类各 20 个问题，以精确匹配准确率评价），并逐例分析失败样本。
  • 局限与迁移会议论文，评估侧重流程可复现性与语义查询准确率，未以分割或诊断等临床终点衡量效果；失败案例集中在缺失或损坏数据与歧义序列选择，说明对 DICOM 元数据质量敏感；本地模型选择、提示设计与规则库维护成本未量化。对本项目，可迁移的是“制品契约 + 确定性执行器 + 本地 Agent”的工程架构，可用于 PET/CT 多中心数据预处理与实验记录的自动化；迁移时需把 SUV 归一化与重建参数检查写成显式规则。

阶段感知反应—扩散神经 ODE：建模 AD 的 tau 与 Aβ PET 长时程进展

纵向 PET 可区域性量化阿尔茨海默病（AD）的 tau 与 Aβ 负荷，但随访稀疏且不规则、疾病阶段与进展速度高度异质，长时程预测困难：机制模型可解释却过于刚性，通用神经 ODE 能处理不规则采样却牺牲机制透明度与稳定性。利物浦大学与葛兰素史克团队提出阶段感知的轻量机制神经 ODE（STARD）：把受连接组约束的扩散—反应骨架与结构化局部残差动力学耦合，包含状态依赖的扩散调制（作用于固定结构连接组）、显式负反馈通道与逻辑斯蒂形状的残差增益，并由一个简单门控模块在潜在疾病时间与全局负荷上路由，同时做受试者特异的仿射时间对齐。在 ADNI 的 tau-PET 与 Aβ-PET 队列上，该方法在留出受试者设定下改善了区域级预测，并揭示出有效耦合与各成分贡献随疾病阶段与生物标志物变化的规律。

  • 研究痛点纵向 tau 与 Aβ PET 随访稀疏不规则、个体疾病阶段与速度差异大，长时程区域预测困难；纯机制模型过于刚性，通用神经 ODE 缺少机制透明度与数值稳定性，二者难以兼顾。
  • 方法与数据阶段感知机制神经 ODE（STARD）：连接组约束的扩散—反应骨架加结构化局部残差；状态依赖扩散调制、显式负反馈通道、逻辑斯蒂残差增益；门控模块基于潜在疾病时间与全局负荷路由，并做受试者特异仿射时间对齐。数据为 ADNI 纵向 tau-PET 与 Aβ-PET，按 Desikan–Killiany 图谱加双侧海马与杏仁核共 72 个区域；留出受试者设定下以区域平方误差和与跨区域相关性评价，并与扩散—反应模型、IGND-MoE、GRU-ODE、ODE-RNN 等基线比较。
  • 局限与迁移会议论文，评估限于 ADNI 单一公开队列，未见外部机构或前瞻验证；机制解释（有效耦合、扩散强度差异）来自事后分析，属假设生成而非因果结论；模型依赖结构连接组与固定图谱分区，跨图谱或跨示踪剂的可迁移性未验证；含商业公司（葛兰素史克）参与。该工作并未使用“世界模型”措辞，本项目按研究画像第 6.3 节 F 中“或实质学习医学状态、环境及其动态转移”的条款纳入。对本项目，可迁移的是“机制骨架与数据驱动残差分离”的建模范式，可用于 PET/CT 病灶负荷的纵向演化建模与治疗反应反事实推演，但需先确定 PET/CT 上的状态定义与随访间隔假设。

多中心 PET/CT 分析之前：先核验 DICOM 几何与定量字段

多中心 PET/CT 研究的性能差异，有相当一部分并不是模型差异，而是元数据层面的几何与定量口径差异。DICOM 标准把空间几何放在图像平面模块，用 Image Orientation (Patient)、Image Position (Patient)、Pixel Spacing 与 Slice Thickness 等字段描述；把定量语义放在 PET 图像模块，用 Units、Decay Correction、Radiopharmaceutical Information Sequence、Patient Weight、Corrected Image 等字段说明像素值究竟代表计数、活动度浓度还是 SUV，以及是否完成衰减、散射与随机校正。这些字段决定了转换为 NIfTI 后体素间距、方向与强度是否一致，也决定 SUV 能否被正确复算。本期收录的 PMCL 显示，扫描协议混杂会让 HD95 在 Dice 稳定时显著恶化；LION 则用视觉嵌入直接观察到同病种不同扫描仪之间的域偏移——两者都指向同一件事：预处理阶段的元数据核验，才是多中心可比性的第一道闸门。

  • 操作要点①对每个中心抽样读取 Image Orientation (Patient) 与 Image Position (Patient)，计算相邻层法向与层间距，核对 Slice Thickness 与实际层间距是否一致；②检查方向行列式的符号与行列是否被交换，统一重采样到标准方向后再做后续处理；③读取 PET 的 Units、Decay Correction 与 Radiopharmaceutical Information Sequence，确认像素值类型，并把 SUV 复算公式（含体重、注射剂量与衰减校正时间）写入元数据表；④记录 Corrected Image 中的校正标记（衰减、散射、随机），不同校正组合的队列不宜直接混合训练；⑤把上述字段整理为结构化清单，作为队列纳入与排除的可核查依据。
  • 适用条件适用于任何多中心 PET/CT、PET 与 SPECT 图像分析，对同一中心跨年代累积数据尤为必要。前提是能取得原始 DICOM 而非已转换的 NIfTI 或临床后处理截图；部分导出流程会在转换环节丢弃或改写这些字段。本条为基于 DICOM 标准与本期论文观察的实践启发，不构成影像中心的操作规范，也不替代本地质控流程。
  • 常见误区最常见的误区是只检查矩阵尺寸与层数、不做方向与层间距一致性核验，导致某一中心的标签与图像被镜像错位却仍能通过流程检查；第二种是把不同 SUV 归一化口径（体重、去脂体重、体表面积）或不同校正状态的扫描直接混合训练，使模型把定量口径当成信号；第三种是认为既然都用 DICOM 就不存在差异，忽略私有标签、重建核函数与后处理带来的隐性域偏移。
