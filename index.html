深度学习-影像组学-SUVmax 融合预测鼻咽癌同步远处转移

鼻咽癌初诊时是否已合并同步远处转移（SDM）直接决定治疗强度，但常规 T/N 分期对 SDM 的判别力有限。研究纳入两中心 218 例病理确诊 NPC 患者（105 例 SDM、113 例无 SDM），分别用 ResNet18、DenseNet121、EfficientNet-B0 在 CT-only、PET-only 与 CT+PET 融合图像上训练，再与原发灶及颈部转移淋巴结的影像组学特征、临床变量和原发灶 SUVmax（SUVmax-T）组合，构建 9 个 MLP 与随机森林模型；另设仅 T/N 分期、仅临床、仅 SUVmax-T、仅深度特征的对照基准。以准确率、精确率、召回率、F1 与 ROC-AUC 评价，用置换特征重要性分析最优 RF 模型的核心预测因子，并对最优混合模型做外部多中心验证。双模态 PET/CT 网络优于单模态，ResNet18 内部 ROC-AUC 最高为 0.804（DenseNet121 0.791、EfficientNet-B0 0.779）。逐步加入影像组学特征、临床参数与 SUVmax-T 后，MLP 混合模型内部 ROC-AUC 达 0.839（召回率 0.747），优于 RF 模型的 0.787（召回率 0.777）。仅用 T/N 分期的模型内部 AUC 为 0.476、外部 0.513，加入深度特征后升至 0.658（内部）与 0.688（外部）。MLP 混合模型外部验证 ROC-AUC 0.701、PR-AUC 0.571。SUVmax-T 被识别为 RF 混合模型中最重要的预测特征。

  • 研究痛点初诊 NPC 是否合并远处转移决定分期与治疗强度，而常规 T/N 分期对 SDM 的判别力接近随机（本研究中 AUC 仅 0.476），缺少可在术前复用、且经过外部验证的无创预测手段。
  • 方法与数据双中心回顾性 218 例（105 SDM / 113 非 SDM）；三种 CNN 架构 × 三种输入模态（CT / PET / CT+PET）；与影像组学特征、临床变量、SUVmax-T 组合成 9 个 MLP 与 RF 模型；设仅 T/N 分期等对照基准；最优模型做外部多中心验证；指标含准确率、精确率、召回率、F1、ROC-AUC 与 PR-AUC。
  • 局限与迁移外部验证 AUC 从内部 0.839 降到 0.701，跨中心泛化仍有限；样本量 218 例、事件 105 例，未报告置信区间；回顾性设计，未与前瞻性随访方案对照；SUVmax 依赖采集与重建参数，跨中心可比性需按核医学定量规范校准。迁移价值：对本项目最直接的可检验假设是「常规分期 + PET 定量 + 深度特征」的分层组合是否优于任一单项；做鼻咽癌 PET/CT 预后建模时应把「仅 T/N 分期」作为必须报告的基线，否则无法判断深度特征的增量价值。

跨示踪剂多模态自监督提升全身 PET/CT 病灶分割

全身 PET/CT 病灶分割要支撑分期、治疗计划与疗效评估，但标注稀缺与域偏移限制了泛化能力；自监督学习在泛癌种、多示踪剂 PET/CT 上仍缺少系统验证。研究提出 MUST-PET：在多机构、跨癌种的 FDG 与 PSMA 两类示踪剂 PET/CT 上做多模态多示踪剂自监督预训练，采用上下文感知的掩码重建——遮蔽其中一种模态的一部分，要求模型用 PET 与 CT 的互补信息把被遮蔽部分重建出来；预训练完成后再用有标注样本微调，并在重建质量、病灶分割、标注效率与跨独立留出数据集的泛化性四个维度上评估。结果显示，重建误差下降，病灶分割优于从零训练，在标注数据有限与未见过的外部数据集上均表现良好。作者的判断是多示踪剂自监督有望支撑标注高效、可泛化的全身 PET/CT 分割。

  • 研究痛点全身 PET/CT 病灶分割的标注成本极高，且不同示踪剂、不同机构之间存在明显域偏移，在单一示踪剂上训练的模型难以跨场景复用。
  • 方法与数据多模态多示踪剂自监督框架，上下文感知掩码重建（遮蔽一模态后用 PET+CT 互补信息重建），预训练后微调；多机构泛癌种 FDG 与 PSMA PET/CT 集合；在独立留出的外部数据集上评估；评估维度为重建质量、病灶分割、标注效率与跨数据集泛化。
  • 局限与迁移预印本，尚未同行评审；摘要未给出数据集名称、样本量与分割指标数值，无法据此判断与强监督基线的差距；作者标注提交至 SPIE CAD 2027，尚未见会议正式收录信息。迁移价值：对本项目可检验的假设是——在鼻咽癌 PET/CT 上先做 PET+CT 双模态掩码重建预训练，能否在仅有少量标注时接近全监督性能；这是需要在自有数据上验证的假设，不能把多示踪剂场景的结论直接外推到单一 FDG 头颈数据。

自监督多模态 Swin UNETR 分割弥漫大 B 细胞淋巴瘤

弥漫大 B 细胞淋巴瘤（DLBCL）的准确分割是 PET/CT 定量与总代谢肿瘤体积（TMTV）估计的前提，但现有深度学习方法多依赖有限标注数据与常规卷积架构，泛化与训练稳定性受限。研究提出用大规模自监督预训练增强的多模态 PET/CT Swin UNETR 框架：单中心收集 717 例 FDG PET/CT，其中 500 例无标注用于自监督预训练，217 例有专家标注用于监督学习；标注集随机分为 174 例训练与 43 例独立留出测试；预处理采用各向同性重采样与体素强度协调。SSL + PET/CT Swin UNETR 在留出测试集上取得 Dice 0.723（95% CI 0.70–0.75）、IoU 0.648、Hausdorff 距离 15.0 mm、HD95 8.8 mm，优于监督基线模型（p<0.001，Wilcoxon 符号秩检验）。TMTV 回归与真实测量强相关（R²=0.929），Bland-Altman 分析显示系统偏倚很小。

  • 研究痛点淋巴瘤 PET/CT 定量依赖病灶分割，而标注规模有限、卷积架构在长程依赖上受限，导致 TMTV 等关键定量指标难以稳定自动化。
  • 方法与数据717 例单中心 FDG PET/CT（500 例无标注预训练 / 217 例专家标注；174 训练 / 43 独立留出测试）；多模态 PET/CT Swin UNETR + 自监督预训练；各向同性重采样与体素强度协调；Dice 0.723（95% CI 0.70–0.75）、IoU 0.648、HD95 8.8 mm；TMTV 回归 R²=0.929。
  • 局限与迁移单中心数据，专家标注仅 217 例、测试集 43 例，且无外部多中心验证；Hausdorff 距离 15.0 mm 提示边界处仍存在大误差；摘要未报告与 nnU-Net 等当前主流强基线的对比；期刊为 Cancer Treatment and Research Communications，评审定位与影像方法专刊不同。迁移价值：「无标注预训练 + 少量标注微调」约 2.3:1 的配比可作为本项目标注不足时的实验设计参照；但 0.723 的 Dice 属中等水平，不能据此预期头颈原发灶分割能达到同等精度。

PET 引导 SPECT 分割：PSMA 双模态上的双中心验证

前列腺癌转移灶在 PSMA PET/CT 与 SPECT/CT 上的手工分割耗时且难以规模化，在广泛转移患者中尤其明显。研究纳入 73 例接受 177Lu-PSMA 治疗的转移性去势抵抗性前列腺癌患者（Henri Becquerel 癌症中心 48 例、南特大学医院 25 例），每人分别在治疗前与第一周期治疗中接受 68Ga-PSMA PET/CT 与 177Lu-PSMA SPECT/CT，由四名核医学医师达成一致后手工分割。基于 nnU-Net 训练四个模型：M1（仅 PET/CT）、M2（仅 SPECT/CT）、M3（PET/CT+SPECT/CT 联合训练、推理时单模态输入）、M4（SPECT/CT 输入并把 PET/CT 分割结果作为先验）。先在 HBCC 数据上训练与内部验证，再用完整 HBCC 队列重训练并在 NUH 数据上外部验证。PET/CT 分割上 M1 与 M3 相当：内部 DSC 0.83±0.19、外部 0.76±0.22（M1），M3 为 0.83±0.16 与 0.77±0.21。SPECT/CT 上 PET 引导的 M4 最佳：内部 DSC 0.63±0.24、外部 0.78±0.14，PPV 分别为 0.65±0.26 与 0.75±0.23；与仅 SPECT 的 M2（内部 0.61±0.26、外部 0.70±0.25）相比，内部验证差异不显著（p=0.35），外部验证显著（p=0.014）。

  • 研究痛点核医学治疗前后需要在 PET/CT 与 SPECT/CT 两种模态上重复勾画转移灶，手工分割在高肿瘤负荷患者中几乎不可扩展，且 SPECT 分辨率更低、边界更不确定。
  • 方法与数据73 例去势抵抗性前列腺癌患者（HBCC 48 / NUH 25），68Ga-PSMA PET/CT 与 177Lu-PSMA SPECT/CT 配对；四名医师一致手工分割为参考；四个 nnU-Net 变体（PET 单模态 / SPECT 单模态 / 联合训练 / PET 分割作先验）；内部加外部验证；DSC 与 PPV 评价。
  • 局限与迁移样本量小（73 例），外部验证仅 25 例；SPECT 分割 DSC 仅 0.63–0.78，标准差达 0.24–0.26，离散度大；内部与外部结果方向不一致（内部不显著、外部显著），说明统计结论本身不稳定；未评估对剂量学参数的最终影响。迁移价值：可检验的结论是「用高分辨率模态的分割结果作为低分辨率模态的先验」这一跨模态迁移策略在 PET/CT 与 SPECT/CT 之间有效；本项目若做 PET/CT 与 CT 或低剂量 PET 之间的跨模态分割，这是一条值得复用的设计，但必须同时报告内部与外部两套结果，不能只报显著的那一套。

级联分割-分类网络让 PET/CT 肿瘤负荷定量更可信

肺癌肿瘤负荷的准确评估对诊断、预后与治疗计划都很关键。为提升分割精度并抑制假阳性，研究提出级联深度学习框架：先做病灶分割，再接入分类阶段剔除假阳性，产出病灶级分割并用于肿瘤负荷定量。数据为单中心回顾性收集的 593 例 18F-FDG PET/CT，来自两台扫描仪；扫描仪 1 的 496 例用于五折交叉验证训练/验证与内部测试，扫描仪 2 的 97 例作为外部测试。以 DSC、病灶级精确率与召回率比较级联模型与单独分割，并把代谢肿瘤体积（MTV）与病灶总糖酵解量（TLG）与手工标注对照。结果：在内部与外部测试集上，级联模型保持了稳定的分割精度（DSC=0.82），且精确率相对单独分割显著提高（P<0.05）。肿瘤负荷估计与手工测量强相关（MTV r=0.984、TLG r=0.998，均 P<0.05），一致性为中等。作者结论是级联结构显著减少假阳性并给出可靠的肿瘤负荷量化。

  • 研究痛点全身 PET/CT 病灶分割中的假阳性（生理性摄取、炎症）会直接污染 MTV 与 TLG 等定量指标，单纯追求 Dice 无法保证定量结果可靠。
  • 方法与数据593 例单中心 18F-FDG PET/CT，两台扫描仪（496 例五折交叉验证加内部测试，97 例跨扫描仪外部测试）；级联「分割 → 分类去假阳性」结构；DSC、病灶级精确率/召回率；MTV 与 TLG 与手工标注对照（r=0.984 / 0.998）。
  • 局限与迁移单中心数据，外部测试仅是同一中心的第二台扫描仪，不构成真正的多中心外部验证；摘要未给出外部测试上的 DSC 与召回率数值，只表述为「一致」；相关性高不等于一致性强，作者自述一致性仅为中等；未评估对分期或治疗决策的影响。迁移价值：最直接的借鉴是评价口径——肿瘤负荷类任务必须同时报告 DSC、病灶级精确率/召回率与 MTV/TLG 的一致性分析，只报 Dice 会掩盖假阳性对定量的影响；这套指标清单可直接用于鼻咽癌 PET/CT 的肿瘤负荷定量实验。

张量影像组学深度学习预测霍奇金淋巴瘤疗效反应

霍奇金淋巴瘤（HL）治疗反应的准确预测关系到个体化治疗强度调整。张量影像组学（TR）通过在多组参数组合上计算特征来优化特征提取，但特征数量庞大、变异性高，给分析与临床使用带来障碍。研究提出 TR-NET，一个从张量影像组学数据中自动完成特征选择并预测治疗反应的深度学习框架，并用可解释 AI 识别最有影响的特征。数据为 18F-FDG PET/CT，通过改变 PET（0.2、0.4、0.6、0.8）与 CT（10、25、50）的 bin width 生成张量影像组学特征集，每个病灶提取一阶、形状、纹理与滤波类（拉普拉斯高斯、小波、平方、平方根、对数、指数、梯度、LBP 2D、LBP 3D）共 13,790 个特征。对比随机森林、XGBoost、SVM 与 TR-NET，并用 SHAP 解释最优模型的预测。TR-NET 的 AUC-ROC 为 0.8470（95% CI 0.7669–0.9185），敏感度 82.2%、特异度 78.2%；XGBoost 为 0.8160（95% CI 0.7457–0.8599），敏感度高（93.3%）但特异度低（66.2%）；随机森林与 SVM 敏感度分别为 92% 与 91.1%，特异度仅 29.5% 与 51.3%。

  • 研究痛点HL 疗效反应预测需要无创工具；张量影像组学特征表达更丰富，但万级特征规模使其难以直接建模，也难以解释模型依据。
  • 方法与数据18F-FDG PET/CT；每病灶 13,790 个张量影像组学特征（PET bin width 0.2–0.8 与 CT 10–50 组合，含一阶、形状、纹理与 9 类滤波）；随机森林、XGBoost、SVM 与 TR-NET 对比；SHAP 可解释分析；AUC 0.8470（95% CI 0.7669–0.9185）。

多机构数据聚合会掩盖基础模型的捷径行为

基础模型在医学影像中的应用增长很快，但其在严重域异质性下的行为仍不清楚。研究用预训练图像编码器作为特征提取器，在覆盖不同采集流程、人群与地理区域的 10 个乳腺 X 线数据集上做分类。结果显示，在聚合后的异质数据上训练的分类器出现依赖数据集的失败模式，各数据集在错误率、置信度与校准上存在显著差异。在表征层面，数据集身份可以从基础模型嵌入中轻易恢复，而临床标签的可分性反而更低，说明「任务信号 / 数据集信号」之比很低。这些结果符合捷径行为：与数据集相关的结构比可迁移的临床信号更容易被下游分类器利用。序贯向量分解进一步表明，大部分可线性恢复的任务信号位于与数据集对齐的子空间中，抑制数据集相关方向后剩余的任务信息有限。探索性元数据分析发现预测概率存在与年龄相关、依赖标签的偏移，提示队列层面的候选中介因素。数据集对抗训练、最差组优化与均衡微调能减少部分数据集层面的差异，但鲁棒性提升往往以牺牲总体性能为代价。

  • 研究痛点把多机构数据聚合起来微调基础模型是常见做法，但聚合带来的性能提升可能掩盖「模型学到机构或设备特征而非疾病特征」的捷径学习，而常规总体指标无法发现这一点。
  • 方法与数据10 个乳腺 X 线数据集（不同采集流程、人群、地理区域）；预训练编码器作特征提取器；在聚合数据上训练分类器；分析错误率、置信度与校准的数据集间差异；用数据集身份可恢复性、序贯向量分解与元数据探索性分析检验捷径；评估数据集对抗训练、最差组优化与均衡微调三种缓解策略。
  • 局限与迁移模态为二维乳腺 X 线，与三维 PET/CT 差异明显；任务为分类，未涉及分割；三种缓解策略均伴随总体性能下降，未给出可操作的取舍准则；元数据中介分析为探索性，未做因果验证。迁移价值：最具操作性的一条是——在聚合多中心 PET/CT 数据训练或微调任何基础模型时，必须按机构或扫描仪分组报告错误率与校准，并检验「机构身份能否从嵌入中恢复」；否则跨中心性能提升可能来自捷径而非可迁移的解剖或代谢特征。这是需要自查后再下结论的验证步骤。

先按 IBSI 校准影像组学特征，再谈融合模型的增益

影像组学特征并不是天然的「客观测量值」：同一个特征在不同软件实现、不同重采样与灰度离散化设置下会给出不同的数值。影像生物标志物标准化倡议（IBSI）由多机构协作制定，通过统一特征定义、计算流程与报告设置，使不同实现之间的特征结果可以对齐，从而让高通量影像表型具备可比性与可重复性。这一点对当前的融合研究尤其关键：本期两篇论文都在做「影像组学 + 深度学习」的组合——鼻咽癌远处转移研究把影像组学特征与 3D-ResNet50 深度特征合并建模，霍奇金淋巴瘤疗效研究在每个病灶上生成 13,790 个张量影像组学特征再做自动选择。如果特征本身的实现与设置不统一、也不报告可重复性，那么「融合带来增益」这一结论的可信度会直接打折。

  • 操作要点① 固定并公开全部设置：重采样方式与间距、灰度离散化（固定 bin width 或固定 bin 数）、滤波与特征族、预处理顺序，写进方法章节；② 用 IBSI 提供的标准数字模体与参考值校验自己的提取管线，或至少与已做 IBSI 对齐的工具（如 Pyradiomics 的对应设置）比对；③ 先做特征可重复性筛选（重扫或重分割的 ICC 阈值，常用 ≥0.75），再做特征选择；④ 特征选择、归一化与超参数必须只在训练折内拟合，测试集与外部集只做一次评估；⑤ 报告提取特征总数与筛选后数量，避免「万级特征直接进模型」导致结果不可复核。
  • 适用条件适用于 CT、PET、SPECT、MRI 等模态上的影像组学以及「影像组学 + 深度学习」融合研究，包括核医学的疗效反应、分期与预后建模。不适用于纯端到端深度学习（不含手工特征）的场景；也不适用于 IBSI 之外尚未标准化的自定义特征集，这类特征需自行验证可重复性后再使用。
  • 常见误区① 认为影像组学特征是客观数值而直接跨研究比较——不同实现与设置下的同名特征数值并不等价；② 在全部数据上先做特征选择或标准化再划分训练/测试，这是典型的数据泄漏，会让 AUC 虚高并在外部验证时崩塌；③ 只报敏感度或只报 AUC、忽略特异度与置信区间——本期霍奇金淋巴瘤研究中 XGBoost 敏感度 93.3% 但特异度仅 66.2%，只看敏感度会给出完全相反的结论；④ 把特征数量的增加当作信息量的增加，在小样本上万级特征只会放大过拟合风险。
