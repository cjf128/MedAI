GET：冻结扩散潜空间内的生成式嵌入翻译分割

生成式分割通过在学习到的潜在表征上操作，为直接像素级预测提供替代方案，但有效的图像-掩膜翻译必须在保持目标结构的同时具备计算效率。研究提出生成式嵌入翻译（GET）框架：在 Stable Diffusion VAE 的冻结潜空间内，通过 U-Net 风格、仅 107 万可训练参数的嵌入翻译网络，逐步将图像嵌入转化为掩膜嵌入，组合了移动瓶颈卷积、子采样自注意力与多尺度特征增强，以分别处理局部建模、全局上下文与多尺度细化。在五个医学分割数据集上，GET 优于生成式、CNN 与 Transformer 基线：相比最强生成式基线 GMS，平均 Dice 与 IoU 分别提升 0.93% 与 1.26%，HD95 降低 0.81 像素，且可训练参数减少 31.41%；在双向 BUS-BUSI 域偏移下，Dice 与 IoU 进一步提升 3.51% 与 3.39%，HD95 降低 27.37 像素。代码已开源。

SymmAdapt：对称流匹配实现无源医学分割域适应

成像模态与采集站点间的域偏移仍是分割模型临床部署的主要障碍。无源无监督域适应（SFUDA）在不访问敏感源数据的前提下将预训练模型适配到无标注目标域。研究提出基于对称流匹配（Symmetrical Flow Matching）的 SFUDA 框架——一个统一生成模型，在同一学习流中既分割输入图像、又从掩膜合成源风格图像。通过从域无关的高斯原点初始化推理，模型跨域保持结构一致性，使预测锚定在学习到的解剖结构而非偏移的纹理统计上；该对称性用于从无标注目标数据生成可靠伪标签与对应源风格合成图像，构成生成式回放缓冲区，在生成式自训练阶段将源知识锚定于真实目标与合成源风格图像的联合集。研究在腹部多器官、心脏分割（跨模态 MRI↔CT）与多站点前列腺分割上评估，性能优于 SFUDA 基线，并与传统 UDA 方法相当。

MedSAM 微调何时有害：表征漂移与域外失效的关联

提示式医学分割基础模型 MedSAM 常以零样本或少样本方式跨域、跨模态泛化，但其性能依赖提示质量与面向定制数据集的适配方式。研究系统考察 MedSAM 在多样医学影像基准上的泛化：六种适配策略（全模型与仅编码器 LoRA、浅层与深层视觉提示微调 VPT、仅解码器与全量微调），在 ISIC 2018 上训练，并在带噪程度递增的提示下于域内与域外（OOD）数据上评估（近域 PH2 皮肤镜、远域 BUSI 乳腺超声与 CBIS-DDSM 乳腺钼靶）。结果显示，适配提升域内与近域性能，却常降低远域性能；全量微调权衡最佳，仅编码器 LoRA 是最强的参数高效替代，在远域偏移下优于标准 LoRA 与 VPT。通过中心核对齐（CKA）分析，远域退化与解码器表征漂移强相关，而编码器相似性本身不能解释稳健性。随机 0–100 像素的提示抖动可产生更稳健、性能更好的模型。研究结论：稳健的 MedSAM 适配需同时考虑提示噪声暴露、域偏移与表征保持。

Aletheia：离线优先的鉴别诊断临床决策支持

撒哈拉以南非洲地区专科医疗资源严重匮乏，农村地区医生与患者比可低至 1:25,000；现有 AI 辅助诊断工具大多依赖稳定网络连接与高配置硬件，对地区医院与基层卫生中心的医护人员并不实用。研究提出 Aletheia——面向低资源医疗场景的离线优先临床决策支持系统：以 Qwen2.5-3B-Instruct 为基座，用 QLoRA 在 5 万条覆盖东非 50 种高发疾病的临床推理样本上微调。评估显示 Top-1 诊断准确率 80.0%、Top-3 准确率 100%、BERTScore-F1 0.909、METEOR 0.467，期望校准误差（ECE）0.275；系统通过非洲深度科技挑战赛 2026（ADTC 2026）768 MB 内存预算约束，在标准化测试笔记本上峰值推理内存约 3,630 MB。研究证明在无云基础设施的资源受限基层场景部署大语言模型临床推理具有可行性。

跨多站点钼靶钙化分类的无监督域适应

基于深度学习的乳腺钼靶计算机辅助诊断在良恶性分类上表现良好，但跨站点域偏移仍是未见过域上应用的主要障碍。研究提出钙化分类框架以提升跨多站点钼靶数据的良恶性鉴别：包含两部分——(1) 基于风格迁移（AdaIN 与 CycleGAN）的无监督域适应模块，无需额外标注即可生成厂商与成像技术特异的训练样本；(2) 以 Swin Transformer V2 为骨干的监督分类模块。研究在三个数据集上评估：OPTIMAM（英国 NHS，n=2,994）内部交叉验证，随后在 EMBED（埃默里大学，n=125）与 Duke 钙化数据集 v1（n=788）外部验证，覆盖多种厂商与全视野数字钼靶、数字乳腺断层合成 2D 图像。该框架将 EMBED 的 AUC 从 0.68 提升至 0.72、Duke 数据集从 0.68 提升至 0.73，表明域适应可降低跨站点域偏移并改善钙化分类泛化。

平衡软专家混合模型：青光眼多模态检测

青光眼是一组损伤视神经的眼病，常由眼压升高引起，是不可逆视力丧失的主要原因之一；早期检测对延缓视力损害至关重要。基于深度学习的单模态模型已提升青光眼检测的准确性与效率，多模态模型则利用不同成像模态的互补优势学习更丰富稳健的表征。然而多模态学习面临联合训练目标导致的单模态表征不平衡与欠优化问题。研究提出带负载均衡损失的平衡软专家混合模型（三个专家）：性能以 AUC 衡量，超过所有单模态基线、常规多模态模型与当前最优的平衡多模态模型；方法可推广到糖尿病视网膜病变等其他疾病检测。

LaST：大小模型协作零样本手术阶段识别

任务特异的轻量手术阶段识别模型擅长捕捉时间动态，但域偏移下泛化差；手术基础模型（FM）通过大规模预训练迁移性更优，却缺乏显式时间建模，常产生时间不一致的预测。研究提出大小时间适配框架 LaST（Large-Small Temporal adaptation），实现到未见临床域的零样本适配：基础模型生成帧级阶段先验作为初始弱监督；迭代时间细化方案结合动态质量控制过滤可靠预测，并以双模型交叉学习缓解确认偏差；轻量模型利用其内在时间建模能力逐步纠正不一致预测。最终通过循环回放策略闭环：精化后的更准确预测作为下一轮迭代的升级监督信号，促进标签质量与模型能力的自强化演化。实验表明 LaST 在未见域零样本手术阶段识别上稳健适配，准确率较基线 PeskaVLP 提升 24.85%–43.17%，甚至超过全监督线性探测与多种少样本方法。

ADMIL：病理基础模型的选择性推理加速

基于病理基础模型嵌入的注意力多实例学习（ABMIL）对全切片任务有效，但穷举式推理需将大型图像编码器应用于每个前景切片块，而后续注意力分布往往集中在少数信息区域。研究提出 ADMIL（Attention-Distilled Multiple Instance Learning）选择性计算框架：将 ABMIL 教师的注意力蒸馏到轻量切片选择模型 PriorNet（EfficientNet 架构），以 KL 散度从原始切片像素学习教师注意力分布；推理时对前景池打分、选择 Top-K 切片，仅对该子集调用昂贵的基础模型，再由基于所选包的 ABMIL 学生预测切片标签。在 BRACS、PANDA 与 CAMELYON16 上，ADMIL 分别以 K=4、8、128 个切片匹配全教师头部性能，避免超过 98% 的基础模型（Virchow2）切片嵌入与推理 FLOPs；随机与教师注意力 oracle 对照表明结果依赖任务相关选择而非单纯切片数削减。研究显示可去除几乎全部昂贵切片编码而不损失切片级性能，为延迟与算力受限的临床部署提供路径。

ReMAP：自监督揭示麻醉下脑表征与脆弱性

全身麻醉提供了在标准化受控扰动下观察人脑的罕见机会，但术中脑电（EEG）几乎总被压缩为单一专有深度指数，丢失大脑在状态间移动的轨迹信息。研究询问轨迹的几何形状（而非仅达到的深度）是否携带临床有意义的信息：使用基于相似性的自监督学习处理原始双电极额部 EEG（无标签），将每次记录置于低维空间中，麻醉深度成为可读轴之一，而患者路径形状编码额外结构。表征在两个队列、两套采集系统、共 1,000 余名患者上验证：麻醉深度预测准确（BIS 平均绝对误差 3.2，R²=0.82），在稀疏导联设置下，其紧凑模型（6.8 万参数）与规模大数个数量级（400 万–1.57 亿参数）的 EEG 基础模型竞争力相当。学习空间还无监督地组织出年龄梯度，并与额叶 alpha、慢 delta、爆发抑制等可解释麻醉特征对齐。在独立纵向随访队列上，早期轨迹几何可区分 30 个月认知与死亡结局（AUROC 0.86），提示麻醉轨迹是潜在脆弱性的标签高效相关物。

BERT-LER：结构化 EHR 的可解释临床预测基础模型

基于结构化电子健康记录（EHR）的预测模型仍是医疗机器学习的核心，但很少有工作同时强调定量检验信息与对输入医疗事件的可解释性。研究提出 BERT-LER——面向编码化 EHR 时间线的 BERT 风格模型，在 7,500 万患者的去标识 EHR 数据集上预训练并微调：将检验结果编码为离散 token，并通过基于百分位数的分箱保留分级信息，配合基于梯度的集成梯度（Integrated Gradients）在输入 EHR 序列上进行 token 级归因。研究在公开 EHRShot 基准套件与基于真实数据的哮喘严重程度进展研究上评估。在 EHRShot 与哮喘任务上，BERT-LER 取得与公开基准模型竞争（检验相关任务上常超越）的预测性能，归因结果与临床已知风险因素一致。研究由赛诺菲（Sanofi）多伦多研发中心主导、卡内基梅隆大学合作参与，属商业机构研发，其架构与可解释方法可应用于多种治疗领域的结构化 EHR 语言模型预测任务。

MediSkill-Evo：过程约束自进化的循证临床交互

交互式临床智能体必须在部分可观测条件下收集关键证据并转化为有依据的行动；仅正确的最终诊断不足以证明智能体遵守了证据与诊疗过程约束。研究提出 MediSkill-Evo——无需骨干微调即可进化受控过程知识的临床智能体：将经验分为临床技能、过程规则、符号模式与测量程序四类知识库，由来源追踪、支持度、回放与控制器定义的安全检查约束其发布到冻结的测试时快照；过程约束偏好框架将证据绑定到来源、拒绝控制器无效候选，并以安全优先的临床过程批判器对行动排序。研究在固定医生轮次限制下、两个骨干端点与六个受控压力维度评估完整系统：300 个留出 Qwen 交互中，诊断准确率从 61.33% 提升至 69.00%，治疗意图覆盖从 33.62% 提升至 66.44%，自动评分的严重失败较 AgentClinic 从 31.00% 降至 16.33%；180 个硬隔离条件下目标恢复在患者行为压力下达 93.61%、时间证据 100%、分诊红旗 92.22%。作者明确说明这些结果是在固定评测套件上的端到端描述性证据，不构成对单个知识库的因果证据或自动评判器的临床验证。

ICU-REACT：教会 LLM 以 ICU 医师方式做临床推理

临床决策依赖识别相关患者信息以指导诊断与治疗，这在数据密集且快速变化的 ICU 尤为困难；大语言模型（LLM）可支持该任务，但现有应用与数据集大多强调表层检索或事实回忆，而非临床医生选择并推理决策相关证据所采用的归纳与演绎推理。研究假设在专家 ICU 推理上训练 LLM 可产生超越重症领域的泛化临床推理能力：构建 ICU-REACT 推理数据集，通过 19 名临床医生参与的临床医生在环框架，训练 LLM 在 ICU 中执行信息检索与上下文感知临床推理；基于该数据集微调 Clin-REACT 模型（8B–70B 参数、三个模型家族）。在五个临床推理基准上，Clin-REACT 一致优于其骨干模型与开源通用及医疗 LLM，增益扩展到脚本一致性测验、下游诊断与治疗任务。研究提示重症领域的专家推理监督可改善更广泛的临床推理，但真实世界临床使用前仍需前瞻性评估。

稀疏多阶段专家路由：复杂临床推理的高效协调

复杂临床推理要求模型随新证据出现更新诊断假设，并在有限会诊资源下协调不同专科；现有基于 LLM 的临床推理系统多为单次预测或固定多智能体工作流，专家参与或静态或过度穷举。研究提出稀疏多阶段专家-智能体路由——将诊断建模为分阶段路由过程的语言化临床推理框架：面对来自多模态的渐进临床证据，框架维护演化中的病例状态，按阶段自适应激活少量医学专家智能体，并由跨阶段专家记忆支持。为超越表面相似性评估自由文本诊断结论，研究引入 ClinFEScore——面向临床推理输出的事实感知语义评估协议。在 MAC 与 AgentClinic-NEJM 重建的多阶段病例上，框架将平均激活专家数从 17.0 降至 3.0，同时保持强事实级诊断质量；200 例真实医院 MDT 病例上，ClinFEScore 与临床医生判断强相关（Spearman ρ=0.81、Pearson r=0.87），方法达到 91.5% 的临床医生核验诊断准确率，每例约五次专家-智能体/LLM 调用。

未来查询：LLM 能否充当隐式医学世界模型

传统临床预测模型依赖任务特异流程与精心整理的结构化数据，扩展性差且未充分利用非结构化文本。研究引入"未来查询"（future querying）范式：通过评估 LLM 回答关于患者未来、带时间索引的临床查询的能力，检验 LLM 能否充当隐式医学世界模型。框架基于端点到无关训练、直接作用于非结构化临床文档，使单一模型无需人工特征工程或任务特异重训即可回答患者轨迹上的多样临床查询。结果显示，小型本地微调的开源权重模型可匹敌或接近更大规模专有系统，使该框架适用于隐私保护的本地部署。研究在新构建的合成医疗报告数据集与 MIMIC-IV 真实 ICU 笔记上评估，为 LLM 能够捕捉临床动力学部分特征提供了初步证据。该工作由 imec 巴黎 AI 实验室主导。

双示踪剂不一致：前列腺癌 PET/CT 分割的多模态融合研究

研究探讨 PSMA 与 FDG 两种 PET 示踪剂在前列腺癌中的多模态融合策略。使用 DEEP-PSMA 挑战赛数据集，训练示踪剂特异的 3D nnU-Net 基线，比较早期融合（单编码器、单/双解码器）与中间融合（双编码器交叉注意力 U-Net）。结果显示：单示踪剂基线表现强劲（PSMA Dice=0.93，FDG=0.81），而融合模型未能持续超越基线，FDG 分割性能出现退化；研究结论认为示踪剂特异模型仍是更强的基线方案。该阴性结果为双示踪剂 PET/CT 临床分割中的融合设计提供了实证边界，提示在示踪剂特性差异显著时，朴素多模态融合未必优于分而治之的策略。

FEEDS：基础模型驱动的标注高效全癌种 PET/CT 采样

PET/CT 数据集的专家标注成本高昂，制约肿瘤分割模型的规模化构建。研究提出 FEEDS（Foundation Model-Enabled Efficient Data Sampling）——利用视觉基础模型嵌入选择最具信息量与多样性的未标注病例供专家标注的训练策略。与无监督、半监督和主动学习方法不同，FEEDS 是单步训练范式，仅需有限但有代表性的训练集：使用 AutoPET-III 数据集训练，并在三个外部测试集（AutoPET-III、DeepPSMA 与达特茅斯-希区柯克医学中心内部数据集）上验证，FEEDS 在减少 70% 标注负担的情况下达到与全标注（100%）训练相当的性能，为多示踪剂全癌种 PET/CT 的标注预算分配提供了实证方案。

GLOW-FDG：FDG-PET/CT 全身癌症病灶分割开源模型

FDG-PET/CT 全身病灶分割对肿瘤负荷量化与疗效评估有重要价值，但公开模型的跨癌种泛化与外部验证证据有限。研究发布 GLOW-FDG——用于 ¹⁸F-FDG-PET/CT 全身癌症病灶分割的开源 AI 模型：在涵盖多种癌症类型的 1,563 次扫描上训练，并在来自独立机构的 185 次外部扫描上评估。在乳腺癌、非转移性与寡转移性肺癌、头颈癌与转移性黑色素瘤中，GLOW-FDG 病灶检测持续优于公开基准模型，同时减少假阳性并保持较强分割准确性；全身肿瘤负荷与总病灶糖酵解量化在多个队列中表现稳健。研究由苏黎世大学医院与德国癌症研究中心（DKFZ）联合团队完成，为可复现的全癌种 PET/CT 病灶分割提供了开放基线。

JAMA 观点文章：AI 超越医生后，监管者不应强制"人在回路"

《美国医学会杂志》（JAMA）发表的观点文章预测，自主 AI 将在医疗推理上超越任何医生-AI 组合，并呼吁监管者不要将"人在回路"写入规则。文章主要论据包括：2024 年以来多数研究中 AI 单独在病史采集、诊断、检查选择、按指南治疗与慢病管理五项核心推理任务上匹敌或超过医生；并引用元分析（106 项实验）认为当 AI 优于人类时，人类复核反而因错误否决而降低结果——如一项基于真实病例的研究中 GPT-4 单独诊断推理得分 92%，而使用同一模型的医生仅 76%。作者以国际象棋为历史类比，并预计到 2030 年自主 AI 可在部分认知工作流中投入使用。需注意作者背景与利益冲突：第一作者 Ezekiel Emanuel 是宾夕法尼亚大学生命伦理学家、美国医改设计者之一；共同作者 Neal Khosla 是 AI 远程医疗公司 Curai Health 的 CEO，其父 Vinod Khosla 同时投资 OpenAI 与 Curai Health，两位作者与该文所倡导的未来有直接利益关系。文章亦承认证据多来自单项任务的模拟而非真实患者照护，手术、分娩、结肠镜等操作性流程短期内仍由人类执行，且自主系统存在幻觉、断网与网络攻击等失败模式。本条目依据 JAMA 原文（2026年8月18日）与 The Decoder 报道整理，属监管观点讨论，不代表临床证据。
