共轭贝叶斯证据学习提升鼻咽癌 GTV 不确定性

鼻咽癌放疗靶区勾画中，原发灶（GTV）在磁共振上边界模糊，确定性分割模型无法刻画这种歧义带来的不确定性；现有证据深度学习（EDL）依赖固定先验，理论上容易发生证据饱和，报告出的不确定性并不可靠。东北大学、中国医科大学附属第一医院与广西医科大学第二附属医院团队提出共轭贝叶斯证据分割框架 CoBESeg：用层次方差证据网络把解剖先验知识与图像驱动证据通过共轭贝叶斯更新显式结合，缓解传统 EDL 的证据饱和；用模糊原型对比学习增强模糊边界区域证据表征的可分性；再用特征距离感知的证据校准在测试时动态调整证据强度。在三套多中心鼻咽癌 MRI 数据集上，CoBESeg 的分割精度与不确定性估计均优于现有先进方法，并支持临床分布漂移下的风险过滤。代码已在作者 GitHub 仓库公布。

  • 研究痛点鼻咽癌 GTV 在 MRI 上边界模糊，确定性模型无法给出与边界歧义程度对应的不确定性；常规 EDL 使用固定先验、易出现证据饱和，导致不确定性估计不可靠，难以用于风险过滤或触发人工复核。
  • 方法与数据回溯性多中心方法研究。核心设计三部分：层次方差证据网络显式融合解剖先验与图像证据并做共轭贝叶斯更新；模糊原型对比学习提升边界区证据表征判别力；测试时特征距离感知的证据校准调整证据强度。在三套多中心鼻咽癌 MRI 数据集上与当前先进方法对比，评价分割精度与不确定性可靠性，并检验临床漂移下的风险过滤能力。摘要未给出数据集样本量与逐项指标数值，需查全文。
  • 局限与迁移原文模态为 MRI，不含 PET；共轭更新、证据校准是否适用于对比度更弱、噪声特性不同的 PET/CT 上 GTVp/GTVn 与转移淋巴结勾画，需要重新验证；跨中心验证基于回顾性数据，缺少前瞻性读数。对本项目，这是鼻咽癌靶区研究可直接追踪的分割基线：可作为 PET/CT 原发灶与淋巴结分割的对照方法，并检验其不确定性是否真能筛出应转人工复核的病例。

术中荧光与术前 PET/CT 融合预测头颈癌淋巴结转移

转移淋巴结（MLN）判定直接决定头颈癌的治疗计划，但既往方法多依赖人工勾画的淋巴结区域或肿瘤轮廓，小病灶与低对比病灶容易被漏掉，良性淋巴结也常因影像特征重叠被误判；这类方法还要求在推理阶段投入大量专家标注。加州大学戴维斯分校团队提出一个患者层面的多模态学习框架，把头颈 PET/CT 的解剖与代谢特征，与术中荧光寿命成像（FLIm）测得的生化特征融合，推理时不需要人工裁剪淋巴结或勾画肿瘤轮廓。影像分支采用融合-分离结构的区域感知 PET/CT 网络，先在 HECKTOR 2022 数据上预训练、再在本机构队列微调；FLIm 的逐点测量与临床变量经多层感知机编码并聚合为受试者级表示；解码阶段比较立方体融合与通道级挤压激励（SE）融合两种策略。在 53 例患者队列上，SE 融合表现最佳，平衡准确率 0.839、AUC 0.872，优于 PET/CT 单独模型（0.815 / 0.828）与 FLIm 单独模型（0.665 / 0.614）。

  • 研究痛点转移淋巴结判定是头颈癌治疗计划的关键，但依赖人工勾画的淋巴结或肿瘤轮廓，小灶、低对比灶易漏诊，良性淋巴结易误判；术前影像与术中生化信息此前没有被整合进同一个患者级预测建模中。
  • 方法与数据患者级 MLN 预测框架。影像侧为基于融合-分离架构的区域感知 PET/CT 网络，先在 HECKTOR 2022 公开数据预训练、再在本机构队列微调，推理时无需人工淋巴结裁剪或肿瘤勾画；FLIm 逐点测量与临床变量经 MLP 编码并聚合为受试者级表示；对比立方体融合与通道级 SE 融合。队列 53 例。结果：PET/CT 单独平衡准确率 0.815、AUC 0.828；FLIm 单独 0.665、0.614；立方体融合 0.827、0.850；SE 融合最优 0.839、0.872。
  • 局限与迁移作者明确说明样本量有限（53 例），结论属假设生成性质，需要更大规模的独立队列验证；FLIm 为术中获得，依赖额外设备与流程，推广受限于具备该条件的中心；未报告外部验证。对本项目，可迁移的是“PET/CT 先在 HECKTOR 预训练再微调、且推理免勾画”的区域感知骨干与 SE 融合设计，但需从 PET/CT 单模态出发在鼻咽癌队列重建，并补齐外部验证与病灶级评价。

纵向 CT 差异报告基准与直接配对推理基线

医学影像基础模型大多只做单次检查的理解，回答不了“和上一次相比发生了什么变化”，而纵向对比正是疗效评估、复发检出与持续患者管理的基础。美国田纳西大学查塔努加分校团队把这一缺口定义为“纵向影像差异报告”任务：给定同一患者两次时间相隔的 CT，直接生成描述间隔变化的临床有意义报告，并发布配套基准 CT-ΔBench。该基准采用患者级数据划分以避免信息泄漏；另设计变化感知指标，以超越表层文本相似度；并通过独立医师验证评估合成参考报告与事件抽取流程的可靠性。研究同时比较了直接配对 CT 推理与“先生成单时点报告、再做文本差分”的两阶段间接路线，并训练了直接配对差异报告的基线模型 DeltaMed。相关数据集已在 HuggingFace 开放。

  • 研究痛点现有医学基础模型基本局限于单次检查理解，无法刻画同一患者两次检查之间的变化；而纵向对比是疗效评估、复发检出与持续管理的核心环节，此前缺少专用任务定义、公开基准与能反映临床变化的评价指标。
  • 方法与数据提出任务与基准 CT-ΔBench：患者级划分防泄漏，变化感知评价指标，并由独立医师抽样验证合成参考报告与事件抽取流程的可信度；对比直接配对 CT 推理与“单时点报告 + 文本差分”两阶段管线；训练直接配对差异报告基线 DeltaMed 并在基准训练集上训练。数据集以 HuggingFace tangkg/CT-DeltaBench 形式开放。摘要与论文页面未给出完整的逐项指标表，具体变化检出数值需查全文。
  • 局限与迁移预印本，尚未同行评审（v1 于 2026-08-12 提交，v2 更新于 2026-09-04）；参考报告由大模型合成、再以医师抽样验证，并非逐例人工标注金标准；任务与数据以 CT 为主，PET 代谢变化语义尚未覆盖；DeltaMed 只是基线而非最优方案。对本项目，这套“患者级划分 + 变化感知指标 + 医师抽样验证”的协议可直接用于构建 PET/CT 纵向疗效评估任务的评价框架。

通用与领域特定自监督预训练结合提升脑 MR 分割

特定人群与疾病的标注数据稀缺是医学影像分析的核心瓶颈，自监督学习提供了从大规模无标注数据中获取可迁移表征的路径，但“领域特定的预训练任务是否优于通用任务”一直缺少受控比较。加拿大卡尔加里大学团队把体素级脑龄预测作为领域特定自监督任务，与常用的图像修复（inpainting）这一非领域特定任务直接对比，并提出多任务自监督预训练框架联合优化两个目标，以学习互补的神经影像表征。预训练模型在多发性硬化病灶分割、缺血性卒中病灶分割与皮层脑结构分割三项下游磁共振分割任务上评估，结果显示多任务预训练在多数实验设置下稳定优于单任务预训练与从头训练，说明把领域特定与通用自监督任务结合有助于构建更可泛化的神经影像基础模型。代码已在 GitHub 公开。

  • 研究痛点特定人群与疾病的标注数据稀缺，迁移学习与自监督预训练是主要对策；但“领域特定 pretext task 与非领域特定任务谁更有效”缺少直接比较，也缺少把两者结合的系统验证。
  • 方法与数据以体素级脑龄预测作为领域特定自监督任务，以图像修复（inpainting）作为非领域特定对照，提出联合优化两者的多任务自监督预训练框架；下游评估为多发性硬化病灶分割、缺血性卒中病灶分割与皮层脑结构分割三项磁共振分割任务，评测涉及 NKI-RS、NKI-TRT、MMRR、Cam-CAN 等公开队列。结论为多任务预训练在多数设置下优于单任务预训练与从头训练，摘要未给出逐任务的 Dice 数值。
  • 局限与迁移预印本，尚未同行评审；结论基于脑 MR 分割任务与有限的下游任务集合，未在 PET 或 PET/CT 上验证；所用多个公开队列之间扫描仪与协议的差异可能影响结论外推。对本项目，可迁移的是“把临床可解释的领域特定预测（如摄取值或代谢分级预测）与通用重建类任务联合预训练”这一设计，用于 PET/CT 分割骨干的预训练，但需重建 pretext task 并做外部验证。

冻结基础模型适配策略与亚组公平性的关系

基础模型被越来越多地适配到下游医学影像任务，但适配策略的选择如何影响不同人群亚组之间的性能差距，此前缺少系统研究。伦敦帝国理工学院团队固定 Rad-DINO 胸部 X 线编码器，比较三种参数高效适配方式——原始 CLS 令牌上的线性头、MLP，以及多层 patch 特征上的注意力池化——对病理分类性能与亚组差异的联合影响。研究在 MIMIC-CXR 上评估八种病理在种族、性别与成像体位亚组上的表现，使用保持患病率的人群均衡测试集，并额外探测每种适配器对受保护属性的编码强度。结果显示注意力池化的整体判别性能最好、对属性（尤其是种族）的编码也最强，但整体性能提升并未一致地缩小亚组差距；值得注意的是，属性编码最弱的早期网络层反而产生了最大的亚组性能差，且池化层组合、属性编码强度与亚组公平性之间没有一致关系。作者据此强调：表达能力更强可以提高准确率，但公平性影响依赖任务且不可预先推断，必须逐任务实测。代码已公开。

  • 研究痛点基础模型的参数高效适配已成为常规操作，但不同适配策略对人群亚组公平性的影响缺乏证据，实践者容易默认“整体性能更好的方案公平性也更好”。
  • 方法与数据固定 Rad-DINO 胸部 X 线编码器，比较三种适配器（CLS 线性头、MLP、多层 patch 注意力池化）在 MIMIC-CXR 上对八种病理的分类表现；在保持患病率且人口学均衡的测试集上按种族、性别与成像体位分层评估，并探测各适配器对受保护属性的编码强度，进一步扫描不同注意力池化层组合。结论：注意力池化判别性能最强、属性编码最强，但整体性能提升未一致缩小亚组差距；早期层属性编码最弱却产生最大亚组差距，三者之间无一致关系。
  • 局限与迁移预印本，尚未同行评审；单一模态（胸部 X 线）与单一数据集（MIMIC-CXR），未覆盖 CT/PET 或三维影像；公平性分析依赖回顾性数据中的属性标签，存在标注与代理变量误差。对本项目，可迁移的是“适配策略 × 亚组公平性”这一评测设计：在 PET/CT 基础模型微调时应把人群亚组指标与整体指标并列报告，不能由整体性能推断公平性。

概念增强的医学视觉-语言跨模态对齐预训练

基于配对医学图像与报告做视觉-语言预训练，是学习医学影像表征的重要路线，但报告在分词过程中容易丢失准确而完整的影像学概念，使全局实例级对齐难以捕捉细粒度病理细节。北京工业大学与首都医科大学附属北京友谊医院团队提出概念增强的医学视觉-语言对齐框架 CoMA：依据放射科医师的认知框架设计“概念子句分解”，从报告中抽取语义完整的病理发现描述作为医学概念子句；在此基础上构建多粒度跨模态对齐，除全局实例级对齐（GIA）外，引入基于双向交叉注意力的概念级令牌对齐（CTA），把图像 patch 与概念子句在病理区域层面建立语义对应；进一步建立由实例级原型对齐（IPA）与概念级原型对齐（CPA）构成的双层原型对齐机制，通过跨模态原型聚类把未配对的高层全局特征与低层概念特征分别拉近。在七个监督式下游数据集-任务设置上，CoMA 表现一致且具竞争力，在标注受限场景下尤其明显。

  • 研究痛点医学报告分词若丢失或割裂影像学概念，视觉-语言预训练只能学到粗粒度对齐，细粒度病理细节无法被有效表征，且在标注受限时性能下降明显。
  • 方法与数据CoMA 框架包含三个组件：基于放射科医师认知框架的概念子句分解（抽取语义完整的病理发现描述）；多粒度跨模态对齐（全局实例级对齐 GIA + 基于双向交叉注意力的概念级令牌对齐 CTA）；双层原型对齐（实例级原型对齐 IPA 与概念级原型对齐 CPA）。在七个监督式下游数据集-任务设置上评测，并报告标注受限设置下的结果；摘要未给出逐任务数值。
  • 局限与迁移同行评审的早期在线版本，具体数值与消融需查全文；方法依赖报告文本与影像的配对数据，概念子句抽取质量取决于报告书写规范；未涉及三维 PET/CT 或多模态断层影像。对本项目，可迁移的是“概念级对齐”思路：PET/CT 报告中的代谢与解剖描述可作为概念子句用于视觉-语言预训练，但需要先建立核医学报告的概念分解规范。

风险约束路由决定医学 Agent 何时需人工接管

医学影像中的智能体系统可以提升吞吐量、降低医师负荷，但自主发生的错误会沿链路传播到下游临床决策，因此关键不只是预测性能，而是判断“何时可以自主放行、何时必须升级复核”。美国圣母大学团队提出 CRC-Router：一个风险约束、不确定性感知的路由模块，既适用于传统的医学预测模型，也可作为智能体式医学 AI 的组件。它把多种互补的不确定性信号与预测分数组合成逐发现（per-finding）的路由特征向量，用轻量级逐发现风险模型把该向量映射为估计的“错误接受风险”，再用共形风险控制（Conformal Risk Control, CRC）在用户指定的风险目标下校准接受阈值。在基于 NIH ChestX-ray14 的胸部 X 线多发现分诊任务上，CRC-Router 在经验风险-覆盖率权衡上优于所比较的基线，且以独立路由层与即插即用模块接入当前先进的 MedRAX 智能体两种形态均成立。代码已公开。

  • 研究痛点智能体式医学 AI 的自主错误会传播到下游决策，仅优化预测性能并不足够；缺少在给定风险目标下决定“自主放行还是升级人工复核”的可校准机制，也缺少对既有预测模型与智能体都通用的模块化方案。
  • 方法与数据CRC-Router 把多种互补不确定性信号与预测分数构造成逐发现路由特征向量，用轻量逐发现风险模型估计错误接受风险，再用共形风险控制按用户指定的风险目标校准接受阈值。在 NIH ChestX-ray14 胸部 X 线多发现分诊任务上与多种基线比较风险-覆盖率权衡，并分别以独立路由层和接入 MedRAX 智能体的插件两种形式验证。
  • 局限与迁移预印本，尚未同行评审；实验基于单一公开数据集（NIH ChestX-ray14）与二分类式多发现任务，风险-覆盖率结论能否迁移到三维 PET/CT 的病灶级任务尚未验证；共形风险控制要求校准集与部署分布可交换，跨中心部署需重新校准。对本项目，可迁移的是“不确定性 + 预测分数共同构成路由特征、以共形方法校准阈值”的设计，可用于 PET/CT 分割或分型的复核触发策略。

原型引导的多模态检索增强介入放射决策

介入放射需要同时对术中影像与专门的临床知识做联合推理，而现有医学检索增强生成（RAG）方法以文本为主、或面向通用医学视觉-语言任务，难以检索到介入场景所需的细粒度视觉-文本证据。南京理工大学、西湖大学与徐州市中心医院团队提出 PRIMA（Prototype-guided Retrieval for Interventional Medical Assistance）：通过解剖感知的视觉-文本对齐与模态保持的表示学习构建多模态介入知识索引；引入领域知识驱动的原型学习来组织介入概念，实现按查询相似度与原型亲和度共同重排证据的原型引导检索。在文献整理数据集与临床采集的介入数据集上，PRIMA 在生成质量、问答准确率与专家评定的临床可解释性上均优于现有 RAG 基线。相关工作已在 GitHub 发布。

  • 研究痛点介入放射的决策依赖术中影像与专门临床知识的联合推理；既有 RAG 方法以文本为中心或面向通用任务，无法检索介入所需的细粒度视觉-文本证据，知识支撑不足。
  • 方法与数据PRIMA 包含三部分：解剖感知的视觉-文本对齐与模态保持表示学习，用于构建多模态介入知识索引；领域知识驱动的原型学习，用于组织介入概念；原型引导检索，按查询相似性与原型亲和度对证据重排。评测使用文献整理数据集与临床采集的介入数据集，指标涵盖生成质量、问答准确率与专家评定的临床可解释性，并与现有 RAG 基线比较。
  • 局限与迁移同行评审的早期在线版本，评测数据集规模与专家评定的具体流程需查全文；知识索引以介入放射文献与本院采集数据为主，迁移到其他亚专业必须重建索引；不涉及 PET/CT 或核医学知识源。对本项目，可迁移的是“原型引导重排 + 专家评定可解释性”这套评测思路，可用于核医学影像问答或报告辅助，但不能直接沿用介入领域的知识索引。

四阶段多智能体框架改进放射报告生成

自动化放射报告生成（RRG）可以减轻医师负荷，但多数系统在单次前向中直接产出报告，既没有把陈述与图像核对的机制，也无法在写下某个发现后回看修正。德国凯泽斯劳滕-兰道大学、德国人工智能研究中心（DFKI）与日本大阪公立大学团队提出 CogRad：一个按放射科医师阅片流程组织的四阶段多智能体框架。Scout 智能体通过 slot attention 直接从图像 patch 发现解剖区域，并给出区域级与疾病级分诊分数；Investigator 智能体把表征容量集中到 Scout 标记的可疑区域；Writer 智能体把这些信号编译成疾病门控的视觉前缀，交给大语言模型生成报告；Verifier 智能体在训练时以视觉蕴含损失监督，在推理时逐句复查自身草稿，对判定依据不足的报告重新生成。在 CheXpert Plus 上取得 BLEU-4 0.316、CIDEr 0.322，为所比较方法中最佳；在 IU X-Ray 上 BLEU-4 0.201、CIDEr 0.724，在所有标准 NLG 指标上优于全部基线。研究还用 RadGraph F1、CheXbert F1 与幻觉分析评估文本重叠之外的临床准确性，并给出消融实验与基于 Grad-CAM 的可视化分析。

  • 研究痛点单次前向生成缺少“对照图像核查陈述”与“回看修正”的机制，一旦某个发现写错就无法纠正；只以文本重叠指标评价会掩盖临床事实错误。
  • 方法与数据CogRad 四阶段结构：Scout（slot attention 从图像 patch 发现解剖区域并给出区域/疾病级分诊分数）→ Investigator（把表征容量集中到可疑区域）→ Writer（生成疾病门控视觉前缀驱动大语言模型）→ Verifier（训练期以视觉蕴含损失监督，推理期逐句复查并重写依据不足的报告）。在 CheXpert Plus 与 IU X-Ray 上评测，指标包括 BLEU-4、CIDEr、RadGraph F1、CheXbert F1 与幻觉分析，并做消融与 Grad-CAM 可视化。
  • 局限与迁移预印本，尚未同行评审；评测限于胸部 X 线报告与两个公开数据集（CheXpert Plus、IU X-Ray），未涉及三维断层影像或核医学报告；未报告放射科医师的前瞻性人工评价与工作流影响。对本项目，可迁移的是“生成—验证”闭环（Verifier 逐句复查）这一结构，用于抑制 PET/CT 结构化报告中的幻觉，但需要重建视觉前缀与核医学概念集合。

分割损失函数怎么选：先看类别不平衡程度

医学图像分割中前景往往只占体素的很小一部分，Dice 类损失因此被广泛使用；但不同损失函数对边界、类别不平衡与噪声的敏感性差别很大，选错时的典型表现是“体素级 Dice 看起来不低，小病灶却被整片漏掉”。Ma 等人在 Medical Image Analysis 上发表的系统比较研究，在多个分割任务与多种不平衡设定下，对二十余种常见损失（交叉熵、Dice、Tversky、Focal、边界距离类损失等）及其组合做了统一实现与受控评测，支持一个可操作的判断顺序：先量化类别不平衡程度与任务目标，再决定是优化区域重叠还是边界距离，最后才是在此基础上做损失组合与权重搜索。它之所以重要，是因为损失函数直接决定模型在“漏检小病灶”与“过度分割”之间的取舍，而这个取舍会改变后续的病灶级指标与临床解释，而且不会体现在训练日志的损失曲线里。

  • 操作要点先量化不平衡程度再选损失：统计前景体素占比与病灶大小分布。区域重叠优先用 Dice/Tversky（Tversky 的 α、β 可分别调节漏检与过分割的惩罚权重）；边界精度要求明确时叠加边界距离项；把 Dice 与交叉熵加权组合通常比任何单一损失稳健，权重应在验证集上网格搜索而不是按经验固定。改损失后必须同时报告体素级指标（Dice、IoU）与病灶级指标（病灶检测率、每例假阳性数），因为损失优化的是体素平均，并不等于病灶不漏。
  • 适用条件主要结论建立在像素级标注的分割任务与受控的不平衡设定之上；多类别任务需按类别或类频率重加权；存在器官先验、多模态输入（如 PET/CT）或交互式提示（scribble/prompt）时，合适的损失权重会变化，需重新搜索。原文包含自然图像与部分医学数据集的比较，不能直接当作临床任务的推荐配方。
  • 常见误区常见误区有三：把 Dice 损失当作“解决不平衡的万能方案”——病灶极小时纯 Dice 的早期梯度可能很不稳定，反而更依赖交叉熵或 Tversky 提供稳定信号；只看体素级 Dice 就判断模型可用，忽略病灶级漏检；在不同损失之间比较时同时改动了数据划分、归一化或阈值策略，导致结论无法归因到损失本身。
